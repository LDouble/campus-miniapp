# Stitch High-Fidelity Replication Rules

仅在用户明确指定 Stitch 页面，或明确要求高保真/1:1 视觉复刻时读取。

## 视觉依据

1. 以用户指定的 Stitch 页面为该任务的视觉依据，同时读取原始 HTML 和截图。
2. 不混用其他版本设计稿，也不只凭截图印象实现。
3. 按原稿核对布局、比例、字体、间距、颜色、圆角、边框、阴影和图标；用户明确要求的差异优先。
4. 若原稿与 OUSea Token 或小程序平台限制冲突，说明具体差异与影响，不静默替换。

## 视觉验收

视觉复刻必须经过真实截图验收，不能用编译、Lint、类型检查或单元测试代替。

1. 统一参考图和实际页面的视口尺寸、缩放、展示数据和页面状态。
2. 使用微信开发者工具自动化截取真实小程序页面；需要渲染 Stitch 原始 HTML 时，可使用 Playwright 生成同尺寸参考图。
3. 做并排、半透明叠加或差异图检查，可使用 ImageMagick、Pixelmatch 等工具。
4. 逐项检查布局、尺寸比例、字体、间距、颜色、圆角、边框、阴影、图标及对齐；必要时局部放大。
5. 跨平台字体抗锯齿等差异需要人工复核，不以单一相似度百分比代替判断。
6. 发现非预期差异后修正并重新截图复验。
7. 工具不可用或未完成截图对比时，明确说明未验证项，不声称完成 1:1 复刻。

交付时给出可访问的参考图、实际图、叠加图或差异图路径，并说明用户允许的差异及仍存在的限制。
