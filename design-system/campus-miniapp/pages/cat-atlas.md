# 猫猫图鉴：校园猫咪影集

## 设计方向

采用单列猫咪 Feed。按照 UI/UX Pro Max 的信息层级、触控尺寸和对比度原则设计，不照搬大宣传区和高饱和多色建议。无收藏入口，也不使用假照片：有真实照片的档案展示原图，没有照片的档案展示无图信息卡。

## 页面结构

- 胶囊适配导航，滚动后显示标题。
- 紧凑品牌介绍与小幅睡猫插画；我的相遇图鉴、发现新猫两个明确入口。
- 搜索、校区下划线筛选、排序。
- 每条 Feed：名字与地点在上方；有照片时展示全宽大图，没有照片时保留名字、地点、性格和相遇次数的信息卡；相遇操作在底部。
- 横图与方图按原比例展示，竖图高度最高为宽度的 125%（4:5），超出部分居中裁切。图片加载前以 4:3 占位；点击图片打开完整原图且不触发详情跳转，名字和信息区继续进入详情。
- 图片预留稳定高度，长名称与地点可换行，加载更多使用简短文案。
- 详情、最近动态、出没地图、我的图鉴、发现新猫和补充档案沿用同一套暖白纸张、可可色文字、焦糖主操作和鼠尾草状态色；使用大圆角、低对比描边和轻阴影建立层次，不混排高饱和颜色。
- 详情页只保留“最近动态”和“我遇到它了”两个固定底部操作；档案补充作为基础档案内的次级入口。动态页顶部是猫咪名、真实记录数和轻量“记一笔”入口，不再放大宣传区与独立引导卡。
- 目击与新猫表单采用全宽照片区和紧凑信息卡，不再使用粗标题、短竖线、数字步骤、逐字段独立外框；提交按钮固定在底部安全区。地点只在点击后请求定位，优先可读地点、支持“其他”手输。地图只展示区域级热点，个人图鉴用暖色进度卡和两列照片网格。
- 最近动态采用作者与时间、活动标签、真实备注、全宽照片、地点与点赞的独立记录卡；长地点独立换行，无照片/备注不制造兜底内容。支持原图预览、下拉刷新、触底和点击加载更多、加载失败重试与点赞防重复。

## Token 与实现

页面、卡片、边框和辅助文字复用 Ousea 全局语义。可可色用于标题，焦糖色用于主要操作，绿色只存在于插画。不逐条分配颜色，不整页铺黄色。暗色沿用全局语义，照片不反色。

列表独立加载 catalog.scss；目击/新猫独立加载 report-journal.scss，隔离旧表单覆盖；最近动态由 sightings-journal.scss 限定独立布局，atlas.scss 仅保留共享基础。其他页面继续使用 atlas.scss。触控区域至少 88rpx，保留安全区和减少动态偏好。

## 业务约束

只改小程序，不改后端和数据库。照片 URL 非空时直接使用后端返回的真实 URL，不替换图片内容；照片 URL 为空时使用无图信息卡，不过滤该档案。保留搜索、校区、排序、下拉刷新、分页、详情跳转。

新猫投稿必须上传成功并取得 mediaId，普通目击照片仍可选。详情、动态、个人图鉴和投稿功能不受入口重设计影响。
