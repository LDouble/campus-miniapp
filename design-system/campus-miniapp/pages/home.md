# 首页视觉覆盖

本文件覆盖 [`../MASTER.md`](../MASTER.md) 中与首页、服务入口和全校通知相关的细节。未写明的内容继续遵循主规范。

## 1. 页面骨架

- 页面内容左右统一使用 `32rpx` 留白，底部为自定义 TabBar 和安全区预留空间；不要让不同模块使用不同的主 gutter。
- 首页采用 Ousea `bg.page` 作为背景，服务区、通知区和内容区使用白色卡片分组。卡片保留 `card-lg` 圆角、浅边框和紧凑的内部间距，不使用无边界漂浮胶囊。
- 区块标题使用“短竖向标记 + 标题 + 可选提示/操作”的组合。标记使用 `ocean-500 → wave-400` 的短渐变，标题和操作在同一行对齐。

## 2. 服务与通知

- 服务入口使用紧凑宫格，图标采用真实 SVG/PNG，图标底板使用统一尺寸和浅色业务底，不使用 Emoji；每个入口保留不小于 `88rpx` 的触控区域。
- 全校通知使用白色圆角卡片，内部采用连续列表和浅分隔线。条目以图标、标题、来源/日期和右箭头建立层级，长标题最多两行，不压缩箭头和触控高度。
- 首页顶部不重复放置通知图标。通知中心和消息入口通过明确的区块/TabBar 进入，避免同一条未读信息出现多个高权重入口。

## 3. 消息角标与生命周期

- 未读消息数只在自定义 TabBar 的消息项上显示数字角标：`1–99` 显示具体数量，超过 `99` 显示 `99+`，为 `0` 时隐藏。
- 应用进入前台时由全局 `onShow` 重新请求未读数；首页重载不能成为请求条件。数据需要同步到持久化值、当前 TabBar 实例，并在下一帧补一次 UI 同步以覆盖冷启动时序。
- 角标使用 `danger-500` 浅量级红底配白字，不与页面内业务色混用；角标不改变 TabBar 图标和文字的布局。

## 4. 移动端反馈

- 首页不提供 hover 视觉。服务入口、通知条目和 TabBar 使用按压时透明度或轻微缩放反馈，动画在 `120–160ms` 内完成且不引发布局位移。
- 固定 TabBar 使用扁平、全宽结构和顶部细边框，不使用悬浮胶囊、强阴影或 backdrop blur；激活项使用 `ocean-500`，未激活项使用 `text-secondary`。

## 5. 交付检查

- [ ] 首页所有主要区块左右边距一致，卡片内部没有多余空白。
- [ ] 通知图标没有与消息 TabBar 角标重复表达同一提醒。
- [ ] 冷启动、返回前台和切换 Tab 后未读数字均能及时更新。
- [ ] 320–375px 宽度下服务入口、标题和角标不横向溢出。
