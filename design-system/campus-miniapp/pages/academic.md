# 教务页面视觉覆盖

本文件覆盖 [`../MASTER.md`](../MASTER.md) 中与课表、成绩、考试、选课结果和通过率相关的细节。未写明的内容继续遵循主规范。

## 1. 头部与学期入口

- `academic-header` 上下使用 `16rpx` 内边距；标题、学期入口和右侧状态在同一布局上下居中。位置由微信导航栏实际指标计算，禁止用固定设备值或 `style="top: x"` 人为偏移。
- 学期入口是轻量文字入口，不使用厚重胶囊、矩形外围或过强边框。文字与向下箭头使用 inline/flex 双轴居中，箭头紧邻文字，不漂浮在行高上方或下方。
- 当前学期始终使用服务端返回的完整文案。仅在真实可用宽度不足时使用单行省略；flex 子项必须设置 `min-width: 0`，空间足够时不提前变成 `...`，不主动生成简写。
- 成绩、考试、选课结果等页面共用这一套入口，不因页面切换重新定义不同的胶囊、字号或箭头位置。

## 2. 信息卡与数据缺失

- 教务卡片优先展示课程、时间、地点、教师和来源等决策信息；标题和元信息按主次分层，操作区使用 Ousea 主色或轻量文字操作。
- 没有通过率数据时不渲染通过率模块、占位文案或空指标卡；卡片内外间距与整体高度随剩余内容收缩。
- 课程备注是可选信息。没有备注时不保留空白分区；有备注时放在课程内容之后的轻量提示区，不抢占课程标题和主要操作。

## 3. 课程详情与 Sheet

- 点击课程后的操作卡使用白色表面、浅边框和轻圆角，主操作突出但不使用高饱和渐变堆叠；内容少时保持紧凑，不用固定高度填满屏幕。
- 底部 Sheet 采用白底和上圆角，关闭 X 是独立图标按钮，不要给 X 再套矩形按钮外围。标题区、主体和操作区的层级清晰，主体超出最大高度时内部滚动。
- Sheet 打开与关闭不改变页面滚动位置；关闭成绩或课表详情后恢复用户进入前的页面位置，避免跳回顶部。
- 选项行使用统一触控高度、双轴居中和清晰选中态；长选项只在真实空间不足时省略，不截断选中状态。

## 4. 课表全局提示

- 接口返回的全局 `note` 在课程列表之后显示为紧凑的 `课表提示` 单行区域。
- 文案未超出容器时静态展示；超出时使用自定义跑马灯：视口 `overflow: hidden`，文本副本线性循环，不能依赖 NutUI `NoticeBar` 或其他第三方视觉组件。
- 跑马灯速度保持低干扰，默认线性循环；`prefers-reduced-motion: reduce` 时停止动画，保留静态可滚动/可阅读内容。

## 5. 交付检查

- [ ] 学期入口在一行内完整展示可展示的真实文案，箭头与文字上下居中。
- [ ] 头部左右信息没有因 `top` 偏移出现一高一低。
- [ ] 没有通过率、备注或其他可选数据时没有空白视觉槽位。
- [ ] Sheet 的 X 无矩形外围，长内容只在主体内滚动。
- [ ] 课表提示在有无溢出、减少动态效果两种状态下都可读。
