# 教务认证页视觉覆盖

本文件覆盖 [`../MASTER.md`](../MASTER.md) 中与校园身份认证、信息门户登录和材料认证相关的细节。未写明的内容继续遵循主规范。

## 1. 布局基调

- 页面采用低密度、原生登录页式布局：顶部保留呼吸感，标题、说明、身份选择、认证方式和表单按纵向节奏排列，不堆叠多层大卡片、光晕或复杂渐变。
- 页面不通过居中大段换行制造视觉重量。说明文案按短段落分组，正文左对齐，重要操作和错误信息靠近对应控件。
- 页面背景、分隔线、文字和主按钮全部消费 Ousea/Global 语义 Token；实色主按钮使用白字，辅助说明使用 `text-secondary` 或 `text-muted`。

## 2. 身份与认证方式

- 身份选择表达“本科生 / 研究生”，初始状态不默认选中，避免用户在未确认时误选教育阶段。
- 两个身份选项必须在窄屏保持横向等宽。实现时使用 `minmax(0, 1fr)`、合理的紧凑间距和 `min-width: 0`，不允许在 360px 及以下设备变成竖排。
- 不再显示“选择认证方式”“任选一种”等冗余说明。认证方式以清晰的标题、辅助描述和选择态表达即可。
- “信息门户认证”是推荐方案；“推荐”使用贴近标题右上区域的浅色角标，角标靠近文字、带独立背景，但不在标题上方另占一整行。
- 材料认证的说明使用“适合无法登录信息门户的同学”，材料要求明确写为“请提供学生证/录取通知书/毕业证”。

## 3. 表单与密码反馈

- 字段标签固定使用“学号”“密码”，标签与输入内容在同一视觉轴线上；输入区以细分隔线或轻表面建立层级，不做厚重输入卡。
- 密码字段使用原生 `password` 输入。右侧提供真实 SVG/PNG 的显示/隐藏图标按钮，触控区域不小于 `88rpx`，切换明文时不丢失焦点和键盘上下文。
- 错误提示就近显示在密码字段下方，采用带浅红底、红色强调线或图标的反馈块，不能使用纯黑 toast 作为唯一反馈。
- coach mark 只在需要引导时出现，并指向密码错误说明/密码帮助区域，而不是遮住输入框；可关闭，关闭后不影响再次输入。

## 4. 密码说明文案

按短段落或编号分组展示：

1. 密码为信息门户密码。
2. 提示密码错误通常就是密码错误，请确认大小写、字符全角/半角。建议在信息门户登录后，直接复制密码过来登录。
3. 如果登录依旧有问题，请添加 `xmxjouc`。

说明区需要支持窄屏换行和滚动，不应挤压主按钮；移除“验证后立即生效”等与当前流程无关的说明。

## 5. 交互检查

- [ ] 未确认身份前没有默认的本科生/研究生选中态。
- [ ] OnePlus Ace2 等窄屏设备上的身份选项仍为横向布局。
- [ ] 推荐角标贴近“信息门户认证”标题，不独占一行。
- [ ] 密码可以显示/隐藏明文，切换时键盘和输入框保持可用。
- [ ] 错误反馈靠近密码字段，coach mark 指向帮助说明。
