# 抽奖详情页

抽奖详情页以暖白与橙色作为活动识别色。页面继续使用 Ousea / Global 的排版、间距、圆角与语义色 Token；抽奖强调色仅用于本业务页面的活动状态、数字和主操作。

- 最新视觉依据为 Figma `3750:2`。设计宽度为 390px，页面左右边距为 16px（`32rpx`），模块间距为 16px（`32rpx`）。
- 页面背景使用 `--ousea-lottery-page`；暖色信息区使用 `--ousea-lottery-warm`；强调色使用 `--ousea-lottery-accent`。三个值由全局 Token 提供，页面不重复声明。
- Hero 使用 16px 圆角、白色表面，标题 20px / 27.5px 并自适应真实长标题；不再保留旧版最小高度。倒计时在细分隔线下，保留时分秒冒号。
- 我的抽奖码使用两列统计与中间分隔线。单奖品卡片全宽，图片区域高 176px；多奖品两列，不伪造额外奖品。概率、库存继续在规则区可读。
- 赞助商内层暖灰卡片展示完整宣传内容，右上“加微咨询”复制真实微信号；可选图片继续保留。WeOUC 使用官方关注组件及降级复制，不能通过复制声称关注成功。
- 底部操作栏固定并避开安全区，按钮高 52px、12px 圆角；分享可用时显示双按钮，否则主按钮全宽。规则默认展开。
- 色彩使用全局 lottery 原始令牌：accent `#EA580C`、page `#FAF7F4`、warm `#FFF7ED`、orange `#F97316`、golden `#F59E0B`；ink/secondary/muted/line 分别为 `#1C1917` / `#78716C` / `#A8A29E` / `#F5F5F4`，仅在本页浅色映射语义色，暗色恢复系统语义色。
- 暗色模式使用现有 `campus-theme--dark` 语义表面、边框与文本 Token，不把暖白背景直接带入暗色界面。
