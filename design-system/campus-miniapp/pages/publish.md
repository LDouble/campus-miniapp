# 统一发布器页面规范

> 本文件只定义 `/pages/publish/index` 相对 Ousea / Global 的页面级差异；未列出的规则继续遵循 `../MASTER.md`。

## 设计定位

发布器采用微信原生内容编辑器式布局，而不是营销页或卡片表单：正文无边界、操作低干扰、业务字段按连续表单分组。用户进入页面后应立即看到可输入区域。

## 页面结构

1. 导航栏只展示当前发布动作，不重复展示 Hero 标题。
2. 导航栏下直接展示四等分发布类型文字 Tab；选中态以业务色文字和底部指示线表达，不使用“发布类型”“草稿自动保存”等说明行，也不使用图标宫格或实体卡片。
3. 正文编辑区使用完整白色表面，不绘制输入框边框；工具栏与正文通过细分隔线区分。
4. 图片编辑器属于正文编辑区，不单独形成页面卡片。
5. 业务信息、发布范围和联系方式使用连续白色分组，分组之间由页面底色形成间隔，不使用悬浮圆角卡片。
6. 固定底栏只保留保存退出、校验错误和主提交动作；键盘弹起时隐藏。

## 业务差异

- 动态：板块使用等宽两列小圆角选项，只展示用户可理解的名称，不展示父模块、子模块等内部层级术语；选中态使用浅色背景和描边，不使用高饱和实色胶囊。话题入口放在正文工具栏，紧邻表情入口；已添加话题回显为可单项移除的小圆角标签。
- 跑腿：按“任务信息 → 补充说明 → 发布范围 → 联系方式”排序；取件地和送达地保留路线节点，截止时间和任务报酬使用连续信息行，正文编辑区适度压缩但仍保留必要的任务说明。
- 二手：交易方式使用“左侧字段标签 + 右侧出售/求购文字选项”，选中项使用业务色文字和短下划线，不设置整组背景底板，避免与顶部业务导航形成第二条满宽导航；售价或预算作为单条重点信息行，不重复展示“交易信息”等无新增语义的标题，也不重复解释图片封面规则。
- 找同行：出发地和目的地复用路线节点；出发时间和同行名额使用左右对齐的连续信息行，不使用不均衡双栏；移除无实际必要的可选说明编辑区。

## 视觉约束

- 页面主体只使用 `page`、`surface`、`surface-subtle`、`border` 和语义文字 Token。
- 业务色仅用于类型选中态、路线关键节点、价格/报酬等关键值和主按钮。
- 正文使用 Ousea `body` 字号；字段标签使用 `caption/label` 层级。
- 主要触控目标不小于 `88rpx × 88rpx`，相邻目标间距不小于 `16rpx`。
- 不使用 Hero、渐变背景、重阴影、玻璃拟态、Emoji 功能图标和页面局部硬编码颜色。
- 暗色模式完全依赖语义 Token；减少动态效果时关闭状态切换动画。

## 话题选择器

- 从底部 Sheet 打开，标题栏固定，支持一次选择最多三个话题；“完成”回到编辑页，单个话题可在 Sheet 和正文工具栏上方的回显区移除。
- 搜索框固定展示 `#` 前缀。检索结果使用连续列表：左侧仅显示单行 `#话题名`，右侧显示“n 条动态”；整行点击选择，不在每一行重复设置“添加”按钮。选中态只用浅色表面与主色名称提示，不把列表项做成一组胶囊。
- 没有精确匹配时，展示“添加”行；点击后先关联到当前编辑中的帖子，提交时由服务端在同一事务中安全创建话题，避免产生无人参与的空话题。
- Sheet 最大高度不超过可用视口的 `76%`，键盘弹起时上移并让结果区内部滚动；遮罩点击可关闭。
