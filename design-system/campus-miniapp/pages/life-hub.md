# 校园生活聚合页设计覆盖

本文件覆盖 `../MASTER.md` 中与校园生活聚合页不匹配的通用建议。

## 页面原则

- 使用轻量扁平层次，不采用大面积玻璃拟态。
- 页面背景为 `#F5F7FA`，卡片为白色并使用细边框，阴影只用于悬浮主操作。
- 四类业务共享字体、间距、圆角和状态语义，但不共享同一种卡片结构。
- 搜索负责关键词，结构化筛选负责服务端查询字段，两者不混为同一控件。

## 业务主题

| 业务 | 主色 | 第一视觉焦点 |
| --- | --- | --- |
| 社区 | `#4F46E5` | 正文、图片与互动 |
| 跑腿 | `#D97706` | 报酬、截止时间与取送路线 |
| 二手 | `#E85D4A` | 商品图、价格和交易状态 |
| 拼车 | `#2563EB` | 出发时间、路线和余座 |

## 筛选规范

- 社区根板块与子板块均来自服务端，并采用两级选择布局。
- 二手首屏显示价格快捷项，自定义价格使用底部筛选面板。
- 拼车首屏显示日期快捷项，路线和座位使用底部筛选面板。
- 跑腿公开接口仅支持关键词，使用范围说明条表达“待接任务”，不显示假筛选。
- 已生效条件必须可见、可单项移除、可全部清除。
- 底部筛选面板打开时隐藏自定义 TabBar，操作栏固定于安全区之上。

## 小程序交互

- 主要触控区域不小于 88rpx。
- 使用 `hoverClass` 提供 150–200ms 点击反馈。
- 图片容器预留尺寸并启用懒加载。
- 遵守 `prefers-reduced-motion`。
- 不使用 Emoji 作为功能图标。
