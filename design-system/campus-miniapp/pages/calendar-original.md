# 校历与校车原件入口

参考 Figma `3756:554`，入口置于页面主体顶部：白色浅边框卡片、浅蓝图标底板、标题与说明、右侧轻量查看操作。复用 Ousea 语义令牌与现有 WebView，保留现有校历和班次查询。

- 校历使用 bootstrap 的 `calender` 字符串（保留该拼写），按钮“查看原件”。
- 校车使用 bootstrap 的 `shuttle` 字符串，按钮“查看图片版”。
- 链接缺省、为空或不是有效 HTTPS URL 时隐藏入口；刷新页面同时刷新配置。
- 只负责打开配置网页，不承诺目标网页具备缩放、下载等未验证能力。
- 日历与右箭头资源直接导出自视觉稿，校车复用项目已有图标。
