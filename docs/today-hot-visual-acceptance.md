## 已修复根因

- 微信 getSystemSetting 同步返回，旧实现直接调用 then 导致组件渲染失败。现在统一等待同步/异步结果，并处理缺失、异常及卸载；新增对应回归用例。
- 首页是 Flex order 布局，新增入口默认 order=0 会跑到头部。现在与日历同组，依据 DOM 顺序位于日历之后。
- 页面缺少 navigationStyle 配置，造成原生栏和自定义栏叠加。主包、分包页面均补齐配置和下拉刷新。

## 验证边界

本次实际截图机型为开发者工具当前 iPhone 模拟器；未做多机型/真机像素一致性承诺。分页、单条/空榜、异常重试等边界另由现有自动化测试覆盖，未将截图视为这些逻辑的证明。线上开关、微信分析事件配置和发布均未执行。

## 2026-09-20：首页「大家在聊」横幅

依据用户最新确认：首页入口更名「大家在聊」，使用蓝青叠放聊天气泡与省略号，取代黄旗/奖杯；入口无白卡边框、阴影和独立卡片圆角，背景渐隐至首页。右侧两行真实话题纵向轮播，不显示热度、排名或浏览量。独立精选页标题同步更名，路由、快照和埋点键保持兼容。

- 入口位于服务区后、课程区前，逻辑尺寸343×60px（375px视口），左右沿用首页16px gutter。
- 原始 Stitch HTML 与渲染图位于工作区 `outputs/gh237-stitch-home/`；原稿白卡/火焰样式由用户后续明确指示覆盖。
- 模拟器验证过自动轮播、触摸暂停、携带 `snapshot_id`、`post_id`、`source=home` 进入精选页。真实帖子来自本地 API；长内容两行截断，纯图帖使用「图片动态」摘要降级。
- 本轮通过 lint、typecheck、test:today-hot、test:design-tokens、test:typography、test:dark-mode、build:weapp 与 git diff --check。完整 CI 已知的 home-guest 源码断言和 master 页面实现不一致不属于本次入口调整。
- 不宣称整页像素级复刻；首页其他模块、原生胶囊、真实内容与原设计不同。
