# 今日上头模拟器验收

## 2026-09-20 验收

使用微信开发者工具 3.17.2 基础库和本地 API `http://127.0.0.1:8080`，真实接口与本地演示内容验证。未连接线上服务。

| 场景 | 结果 |
| --- | --- |
| 首页入口顺序 | 日历之后、常用服务之前，避开微信胶囊 |
| 自动轮播 | 两次间隔 6 秒读取显示不同摘要，默认间隔 5 秒 |
| 首页点击 | 进入独立精选页，携带固定快照与入口帖子 |
| 导航栏 | 仅显示“今日上头”自定义导航，主包/分包均配置 custom |
| 列表结束 | 显示“今天的热门就到这里”和社区按钮 |
| 社区按钮 | 实际跳转 pages/community/index |
| 详情返回 | 进入帖子 7 详情后返回原精选页实例，内容仍在 |
| 深色模式 | 首页文字、入口和服务区可读；验收后恢复原主题 |
| 请求来源 | Network 确认热榜及精选列表均请求 127.0.0.1:8080，返回 200 |

## 已修复根因

- 微信 getSystemSetting 同步返回，旧实现直接调用 then 导致组件渲染失败。现在统一等待同步/异步结果，并处理缺失、异常及卸载；新增对应回归用例。
- 首页是 Flex order 布局，新增入口默认 order=0 会跑到头部。现在与日历同组，依据 DOM 顺序位于日历之后。
- 页面缺少 navigationStyle 配置，造成原生栏和自定义栏叠加。主包、分包页面均补齐配置和下拉刷新。

## 验证边界

本次实际截图机型为开发者工具当前 iPhone 模拟器；未做多机型/真机像素一致性承诺。分页、单条/空榜、异常重试等边界另由现有自动化测试覆盖，未将截图视为这些逻辑的证明。线上开关、微信分析事件配置和发布均未执行。
