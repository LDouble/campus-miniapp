## 已修复根因

- 微信 getSystemSetting 同步返回，旧实现直接调用 then 导致组件渲染失败。现在统一等待同步/异步结果，并处理缺失、异常及卸载；新增对应回归用例。
- 首页是 Flex order 布局，新增入口默认 order=0 会跑到头部。现在与日历同组，依据 DOM 顺序位于日历之后。
- 页面缺少 navigationStyle 配置，造成原生栏和自定义栏叠加。主包、分包页面均补齐配置和下拉刷新。

## 验证边界

本次实际截图机型为开发者工具当前 iPhone 模拟器；未做多机型/真机像素一致性承诺。分页、单条/空榜、异常重试等边界另由现有自动化测试覆盖，未将截图视为这些逻辑的证明。线上开关、微信分析事件配置和发布均未执行。

## 2026-09-20：首页「大家在聊」附件 HTML 复刻（最终版本）

以用户最后提供的完整 HTML 为视觉依据，覆盖此前蓝色横幅版本。入口使用白底圆角、细描边、浅阴影、橙色渐变聊天图标和右侧「热聊榜」。SVG 路径直接取自原稿。原稿 w-4.5 未生效，浏览器实际图标为 32px，按实际渲染还原。

- 375px 视口中入口宽351px；原稿高78.5px，微信 rpx 取整后78px。品牌字号11px，图标32px，中央52px视窗、两条22px话题。入口仍位于常用服务之后、课程之前。
- 每两条真实帖子一屏；奇数末屏保留单条，不复制填充。逐行点击进入独立精选页并定位各自 post_id；右侧与品牌区定位当前首条。保持快照、埋点与接口不变。
