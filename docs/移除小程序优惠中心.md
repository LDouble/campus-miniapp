# 移除小程序优惠中心

## 范围

移除小程序优惠中心Tab、首页、搜索、商品详情和口令二级页；删除对应Tab图标和入口专用的四个外部小程序AppID声明。后台服务、商品数据与管理端不变。

完整版Tab为首页、社区、消息、我的；资格版为首页、消息、我的。Tab选中索引不再取决于服务端优惠能力开关。首页双击Tab回顶、社区点击回顶和消息角标保留。

## 验收

- 构建产物无 `pages/goods` 页面注册或页面目录。
- 模拟器消息页选中索引2、我的页索引3，实际Tab列表为四项。
- 本地lint、类型检查、相关回归和小程序构建通过后交付；代码修改不代表已上传或发布。

旧版小程序仍可使用后台接口；旧优惠页面路径在新版本不再提供。共享优惠业务模块与接口类型暂保留，但不由Tab或启动预热引用。
