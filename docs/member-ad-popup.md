# 会员广告支持浮层

## 展示规则

- 使用 Stitch 项目 `15622041428229605892` 的 `ed5a1ee41b90411a8b5c6c14e9f36c61` 横趴柴犬设计。广告示意卡替换为微信原生广告，实际内容和高度由微信决定；移除底部 X，用户可点击遮罩关闭。
- 仅 `/auth/me` 返回角色包含 `member` 的用户可展示，资格版不展示。
- 使用 `wx.preloadAd([{ unitId: 'adunit-4f79eb2b54ba62ae', type: 'custom' }])` 预热；旧基础库不支持时回退到组件正常加载。预加载调用不是成功信号，必须等待 `AdCustom.onLoad`。
- 准备阶段不显示遮罩、不拦截滚动。滚动不取消会员广告，仍避让通知、评论、课程快捷提问和校区提示。
- 运营活动优先：活动图片真正呈现后，本次不再紧接着展示会员广告；候选、图片或资格申请失败，以及活动因用户操作取消时，不消耗广告展示资格。
- 离页、身份切换、广告失败或加载超过 8 秒会取消准备。展示后没有自动关闭倒计时；重新进入首页时会重查频控，同一页面实例跨过 72 小时后也可重新尝试。

## 三天频控

频控为当前设备按用户账号记录的连续 **72 小时** 间隔，不是自然日，也不提供跨设备一致性。

1. 调用广告预加载前检查到期时间；准备挂载广告前再次检查。
2. 广告加载成功只表示已准备好，不写频控记录。
3. 没有其他弹层占用、首页仍活跃且身份有效时，浮层变为可见。
4. 可见状态提交到原生视图后的 `nextTick` 才记录展示时间。同一组件只记录一次。
5. 加载失败、超时、离页、被其他弹层持续挡住或原生可见状态提交前取消，都不消耗频控。

记录沿用 `campus.member-ad-popup.v1.<用户ID>`，不因应用版本或页面重建重置。无法读取或记录损坏时保守跳过；实际展示后写入失败则保留当前运行期的内存记录。设备清除存储会丢失本地频控记录；若需要跨设备和清缓存后仍有效，应另行接入服务端频控。

## 验收矩阵

| 场景 | 预期 |
| --- | --- |
| 非 member 或账号无效 | 不预加载、不展示 |
| 首次或距离上次展示已满 72 小时 | 可准备广告 |
| 距离上次展示不足 72 小时 | 不预加载、不挂载广告 |
| 广告未触发 load | 浮层不可见，页面可操作，不记时 |
| 广告加载成功但其他弹层仍占用 | 等待，不记时 |
| load 后符合显示条件 | 显示浮层，原生可见状态提交后记时一次 |
| 用户滚动期间 load | 可展示；滚动不取消广告 |
| 加载失败、超时或离页后回调 | 不展示、不记时 |
| 切换账号 | 按新账号记录判断，旧账号回调不能展示 |
| 重启或应用版本变化 | 仍读取该账号的本地展示时间 |
| 记录损坏、时间回拨或读取失败 | 保守不展示 |

## 验证

- `yarn test:member-ad`：角色、72 小时边界、账户隔离、存储异常，以及真实组件回调的准备、展示、失败、超时和卸载顺序。
- `yarn test:activity-popup`：相邻运营活动弹层回归。
- `yarn lint`、`yarn typecheck`、`yarn build:weapp`、`git diff --check`。
- 微信模拟器已验证预加载 API 存在、透明准备中的原生广告能收到 load，以及滚动后的完整浮层展示；真实手机加载时序仍需设备验证。
