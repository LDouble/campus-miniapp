# 小程序主包体积控制

## 本次超限原因

会员广告浮层加入后，微信上传返回主包 2130KB，超过 2048KB。该次本地完整产物的主包原始文件共 2,249,622 字节；微信上传会再次处理产物，两个统计口径不能混用。

主要占用为 JS 约 1100KiB、WXSS 约 733KiB、PNG 约 184KiB、SVG 约 85KiB。大文件包括公共 JS（355KiB）、公共 WXSS（175KiB）、首页 WXSS（160KiB）和全局主题 WXSS（113KiB）；新浮层的柴犬 PNG 为 73,579 字节。

## 修复范围

- 首页和话题页通过同一个 webpack 样式模块复用社区列表样式，避免 Sass 在页面样式中再次内联。保留首页、话题页自己的覆盖规则和全局公共样式导入。
- 小程序 Autoprefixer 排除 IE，保留 Android 4.1、iOS 8 和必要的 WebKit 回退；H5 构建目标不变。
- 小程序 Terser 使用 UTF-8 输出中文，关闭逐字 ASCII 转义；不改变压缩算法及小程序兼容选项。
- 构建后将仅由分包 webpack 资源模块引用的图片、图标放到对应分包 `_resources/`，改写资源模块导出的绝对路径。多个分包使用时分别复制，主包仍使用的资源保留在主包。资源文件内容不变，柴犬保留原 PNG。
- 动态拼接、相对路径、非资源模块引用、带外部依赖的 SVG，以及未被引用的文件均不自动迁移。目标已有不同内容时阻断，不覆盖。

## 构建入口与守卫

`yarn build:weapp` 和 `scripts/build-weapp-edition.sh` 共用 `scripts/build-weapp.sh`。生产构建先完成 Taro 编译，再归位资源，最后检查主包原始文件体积不得超过 2MiB。开发 watcher 保留原始增量构建，参数原样传给 Taro。

体积检查按 `app.json` 的分包根目录排除分包文件，使用 UTF-8 文件的实际字节数，输出最大的十个主包文件。采用未经过 IDE 二次压缩的体积作保守门禁；最终是否可上传仍以微信实际打包结果为准。

```sh
node scripts/package-size-smoke.cjs
node scripts/check-weapp-package-size.cjs dist/full
```

回归覆盖分包路径边界、UTF-8 字节统计、主包超限退出失败、资源字节保真、跨包复制、主包共享保留、相对与动态路径保留、外部 SVG、重复执行和目标冲突保护。发布时还应核对实际产物中的资源目标可读及各分包体积。
