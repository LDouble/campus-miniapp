# 微信小程序对象存储上传域名

图片与资料通过后端签发的短时目标，使用 `wx.uploadFile` 直传对象存储。客户端不配置、保存或打印 OSS AccessKey。

部署或切换 Bucket 后，需要在微信公众平台的「开发管理 → 开发设置 → 服务器域名」中，将后端实际返回的 `upload_url` 主机加入 `uploadFile` 合法域名。仅填写 HTTPS 域名，不填写对象路径、签名查询参数或控制台地址。

不同环境或 Bucket 使用不同上传主机时，应分别登记对应环境实际签发的主机。上线前至少验证课程资料、学生认证、社团图片、社区图片、二手图片和头像上传；若模拟器提示 `url not in domain list`，先核对后端当前签发的主机与公众平台配置，不要关闭生产环境域名校验。
