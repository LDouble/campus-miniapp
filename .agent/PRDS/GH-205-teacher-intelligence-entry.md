# 小程序：教师统计增加选课情报入口

**Priority:** Medium
**Status:** Approved
**Type:** Enhancement
**Created:** 2026-09-08
**Last Updated:** 2026-09-08

## Overview

课程参考页的“历史授课教师”卡片目前只能打开教师通过率与学期趋势面板，无法继续查看该教师对应的学生原始观点。增加一个明确入口，将教师统计与选课情报串联起来。

## User Story

**As a** 正在比较授课教师的学生  
**I want** 从教师历史统计面板直接查看该教师的选课情报  
**So that** 我可以结合成绩统计和学生原始经验做判断。

## Implementation Overview

- 在教师统计底部面板增加“查看该教师选课情报”按钮。
- 点击后关闭教师统计面板，将课程参考页切换到“选课情报”标签。
- 将当前教师姓名传给情报阅读组件，由现有教师映射结果自动选中对应教师。
- 如果该教师没有情报映射，保留“全部教师”范围，不阻断课程级情报浏览。
- 不新增页面和后端接口，复用现有课程情报组件、鉴权和查询链路。

## Files to Modify

- `src/pages/academic/statistics/index.tsx`：增加入口、标签切换和教师上下文传递。
- `src/pages/academic/statistics/index.scss`：增加符合 Ousea / Global 的次级操作样式。
- `scripts/academic-statistics-smoke.ts`：覆盖入口和教师上下文回归检查。

## Acceptance Criteria

- 教师统计面板展示“查看该教师选课情报”入口。
- 点击入口后面板关闭并切换到“选课情报”。
- 有教师映射时自动选中对应教师，情报概览与评论请求携带正确的 `teacher_id`。
- 无教师映射时仍能展示课程级情报，不出现空白页或错误循环。
- 入口具备清晰的可访问名称，暗色模式和底部安全区下可正常使用。
- 定向 ESLint、TypeScript、回归测试及 `build:weapp` 通过，并在微信开发者工具模拟器验证。

## Risks / Considerations

- 成绩统计教师姓名与情报教师规范名可能存在空格或别名差异；继续复用现有去空格匹配，不在前端创建新的别名规则。
- 切换标签时必须先关闭固定定位的底部面板，避免遮挡情报内容。
- 教师筛选应由情报组件现有加载流程完成，避免页面层重复请求接口。
