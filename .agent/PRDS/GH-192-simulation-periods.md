# Miniapp：修复模拟选课学期列表

## 1. 背景

模拟选课课表当前根据本地第一门模拟课程的 `periodId` 创建一个临时学期，因此学期选择器只有一个选项，且学期名称直接显示 ID。用户无法在模拟课表中查看或切换其他可用学期。

## 2. 目标

让模拟选课课表与课程检索页使用同源的校历学期列表：展示完整学期选项，默认进入当前学期，切换后按学期过滤本地模拟课程。

## 3. 方案

- 模拟选课页按当前学历读取校历接口返回的完整学期集合。
- 使用服务端 `is_current` 确定默认学期；没有当前标记时回退到返回列表中的第一个有效学期。
- 保留本地模拟课程的 `periodId`，不把课程复制到其他学期，也不改变真实课表请求和缓存。
- 校历加载失败时优先使用本地已知模拟课程生成最小兼容列表；课程不存在时展示空状态并保留重试能力。
- 学期选择仍复用现有课表入口与单选 Sheet，不新增页面级视觉样式。

## 4. 非目标

- 不把模拟选课课程保存到服务端。
- 不改变课程检索、蹭课课表、真实课表的学期接口和筛选逻辑。
- 不改变模拟选课课程的添加、移除和按选课号聚合行为。

## 5. 验收

1. 有多个校历学期时，模拟选课页学期 Sheet 显示全部学期。
2. 首次进入默认当前学期，并展示该学期的模拟课程。
3. 切换历史学期只展示对应 `periodId` 的模拟课程。
4. 空模拟课程、校历请求失败和旧版本只有单个模拟学期数据时不崩溃、不展示错误的固定学期标签。
5. 通过 `yarn test:academic-schedule`、`yarn lint`、`yarn typecheck` 和 `yarn build:weapp`。
