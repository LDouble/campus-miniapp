# 海大校园小程序：首页信息层级与卡片密度优化

**Priority:** High
**Status:** Done
**Type:** Enhancement
**Created:** 2026-08-20
**Last Updated:** 2026-08-20

## 概述

在现有首页视觉和全局字体 Token 基础上，移除重复或低价值信息，压缩首屏纵向占用，并核对日程卡片对课程、考试和推荐校历事件的实际支持范围。

## 用户目标

1. 校区筛选只展示当前校区，不重复展示学校全称。
2. 日程卡片不重复顶部已经提供的学期或开学日期信息。
3. 常用服务标题区更紧凑，服务入口仍保持清晰和足够点击面积。
4. `OFFICIAL` 与“全校通知”在同一行显示。
5. 日程卡片文案必须与真实数据聚合能力一致，不承诺尚未接入的考试数据。

## 当前行为核对

- 课程：展示课表缓存中今天剩余课程；若今天无剩余课程或时间超过 22:00，则展示明天课程。最多展示 2 条。
- 推荐校历事件：展示未来 14 天内、命中当前校区且标记为 `homepage_recommended` 的事件。最多展示 2 条。
- 考试：当前首页没有读取考试缓存，也没有调用考试接口，因此不会展示考试安排。
- “全部日程”当前实际进入校历页，不是课程、考试、校历三类数据的统一列表。

## 实现方案

1. 将校区选择器文案由“学校全称 · 校区”改为只显示校区。
2. 日程标题直接使用 `coursePreview.dayLabel`（今天、明天或假期），移除重复日期；右侧入口改为语义准确的“校历”。
3. 空状态使用 `coursePreview.emptyText` 与 `coursePreview.emptyHint`，移除“考试会汇总在这里”的误导性承诺。
4. 删除常用服务副标题，将标题、全部入口和服务网格收紧为单层信息结构；服务项整体点击区域仍不低于 44px。
5. 为通知标题增加显式 heading 容器，让 `OFFICIAL` 与“全校通知”水平排列并缩短标题区高度。
6. 保留现有字号、字重、颜色 Token，不新增页面私有字体值或新的视觉风格。

## 不包含

- 本轮不新增考试接口请求或考试缓存刷新策略。
- 不建设课程、考试、校历三类数据的统一日程详情页。
- 不改变服务入口数量、顺序、路由和功能开关。
- 不修改首页其他内容模块的顺序和数据加载。

## 修改文件

- `src/pages/index/index.tsx` - 精简文案和标题结构，修正日程空状态语义。
- `src/pages/index/index.scss` - 压缩服务、通知标题和对应卡片间距。
- `src/features/home/data.ts` - 修正课表缓存尚未同步时误切到“明天”的预览状态。
- `scripts/home-guest-smoke.ts` - 锁定校区、服务和通知的新语义结构。
- `scripts/today-home-smoke.ts` - 锁定日程标题、空状态和真实聚合范围。
- `scripts/typography-smoke.ts` - 将已删除服务副标题的字体断言迁移到仍存在的正文操作项。

## 验收标准

1. 首页校区筛选不再出现“中国海洋大学”。
2. 日程卡片标题不再重复具体日期，并能正确显示今天、明天或假期状态。
3. 页面不再宣称考试已进入首页日程聚合；课程和推荐校历事件逻辑保持不变。
4. 常用服务副标题消失，标题区和三行服务网格的总高度下降，服务入口仍可正常点击。
5. `OFFICIAL` 与“全校通知”保持单行，长文本和右侧“查看全部”不发生重叠。
6. 375px 与 390px 视口无横向溢出，暗色模式和减少动态效果规则继续命中。
7. 首页相关 smoke、字体 smoke、类型检查、Lint、小程序构建和模拟器预览通过。

**Implementation Notes:**

用户已逐项指定需要精简的首页区域，本 PRD 作为当前首页改造的补充记录，并按该明确授权直接进入实现。

UI/UX 检索建议采用紧凑的数据型移动首页、减少无信息价值留白并保证点击区域。现有系统字体、颜色和圆角体系已经确认，因此本轮只采用“提高信息密度”的布局建议，不引入检索结果中的字体、金色配色或新视觉风格。

最终实现中，校区选择器仅显示“崂山校区”等当前校区；日程标题使用真实 `dayLabel`，本次生产状态正确显示“假期”，右侧入口改为语义准确的“校历”。空状态复用课表预览已有的状态和提示，不再宣称首页已汇总考试。

动态标题在预览中暴露出一个原有边界问题：课表缓存尚未同步时，旧逻辑会把“今天无剩余课程”误判为应该预览明天。现已让无缓存状态固定使用“今天 / 课表尚未同步”，并通过 smoke 锁定该行为；有缓存时的今天剩余课程、22:00 后切换明天和假期判断保持不变。

常用服务删除副标题并收紧卡片上下内边距和网格间距。390px 模拟器中标题操作区约 47px、整张服务卡约 256px，服务项仍约 60px 高。通知标题改为单行 flex 布局，标题点击区实测约 45px 高。

模拟器截图：`/tmp/home-compact-hierarchy-final-v2.png`、`/tmp/home-compact-official-final.png`。WXSS 编译通过；Console 未匹配到 error/exception/failed，Network 未匹配到 4xx/5xx。首页、日程、字体、暗色 smoke、TypeScript、ESLint 和微信小程序构建均通过。
