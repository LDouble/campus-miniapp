# 小程序：蹭课卡片增加通过率入口与详情浮层

**Priority:** Medium
**Status:** In Progress
**Type:** Enhancement
**Created:** 2026-09-06
**Last Updated:** 2026-09-06

## Overview

在蹭课检索页的课程卡片上增加课程通过率入口。用户无需离开课程检索页即可先查看匿名历史成绩汇总，再按需进入完整的课程通过率详情页。

## User Story

**As a** 需要判断是否旁听某门课程的同学
**I want** 在蹭课课程卡片上快速查看课程通过率，并能继续查看趋势和教师维度详情
**So that** 我可以在决定加入蹭课前获得更多课程信息。

## Context

课表页已有课程通过率预览组件和课程统计详情页，但蹭课课程卡片目前没有入口。蹭课页与课表页使用相同的课程代码和课程参考数据口径，应复用现有数据请求、缓存、绑定引导和详情导航，避免形成第二套统计实现。

## Implementation Overview

- 在蹭课课程卡片中增加紧凑的“查看通过率”入口，不改变“模拟选课 / 蹭课”主操作的优先级。
- 入口点击后展示课程通过率浮层，浮层展示历史通过率、百分制平均分和样本状态；数据加载中、无数据、绑定要求和请求失败均有明确反馈。
- 浮层点击后复用 `openCourseStatistics` 进入课程通过率详情，并携带课程代码、课程名和当前教师名。
- 优先复用 `CoursePassRatePreview` 的统计数据逻辑和 `getCoursePassRatePreview` 的缓存行为；如需支持浮层展示，抽取共享的展示/状态组件，不复制接口请求。
- 遵循 Ousea / Global 及教务页面规范，适配暗色模式、窄屏、安全区、点击遮罩关闭和减少动态效果。

## Features / Requirements

1. **蹭课卡片入口**
   - 课程存在有效课程代码时显示“查看通过率”入口。
   - 入口是轻量文字/次操作，不与加入蹭课、模拟选课按钮争夺首要视觉层级。
   - 缺少课程代码时不展示空入口或占位区域。

2. **通过率浮层**
   - 点击入口后在当前页面展示浮层，不直接跳转。
   - 浮层展示历史通过率、百分制平均分、样本状态和课程名称/教师上下文。
   - 点击遮罩或关闭按钮可返回原课程列表，关闭不改变列表滚动位置。
   - 加载、暂无数据、登录绑定要求、网络失败和缓存数据状态均有可理解的文案。

3. **详情跳转**
   - 浮层的主要操作进入现有课程通过率详情页。
   - 详情页参数包含 `course_code`、`course_name`、`teacher_name`，并与课表页进入详情时保持一致。

4. **视觉与兼容性**
   - 复用教务页语义 Token，不新增页面专属基础色。
   - 暗色模式下浮层、遮罩、边框、文本和操作状态均可读。
   - 窄屏不横向溢出；微信小程序模拟器和构建产物可正常编译。

## Files to Create

## Files to Modify

- `src/pages/academic/course-catalog/index.scss` - 增加入口与浮层的 Ousea/暗色模式样式。
- `src/features/academic-statistics/course-pass-rate-preview/*` - 在需要时抽取可复用的预览内容或浮层状态，不改变既有课表行为。
- `scripts/*-smoke.ts` - 增加蹭课入口、浮层与详情参数的静态回归检查。

## API Endpoints

不新增接口，复用现有课程通过率接口、缓存和详情页数据请求。

## Acceptance Criteria

- 蹭课卡片在有课程代码时显示通过率入口，缺少课程代码时不留空白槽位。
- 点击入口出现通过率浮层，浮层数据与课表页课程参考口径一致。
- 浮层可以关闭，并能进入现有课程通过率详情页。
- 详情页收到正确的课程代码、课程名和教师名。
- 加载、空数据、错误、绑定引导、缓存数据、暗色模式和窄屏均可理解且无溢出。
- `yarn lint`、`yarn typecheck`、`yarn test:design-tokens`、`yarn test:typography`、`yarn test:dark-mode`、`yarn build:weapp` 通过。

## Risks / Considerations

- 蹭课课程可能没有课程代码，必须让入口按数据条件隐藏，不能触发无效请求。
- 浮层不能被课程卡片或页面点击事件误关闭，需阻止事件冒泡。
- 课程统计接口可能要求先绑定教务身份，应复用现有绑定引导而不是新增登录流程。
