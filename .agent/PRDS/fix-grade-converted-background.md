# Campus Miniapp: 修复成绩折算说明的异常背景条

**Priority:** Medium
**Status:** Done
**Type:** Bug
**Created:** 2026-08-16
**Last Updated:** 2026-08-16

## 问题

成绩查询页的等级制课程会展示“折算 xx 分参与加权平均”。当前 `.grade-card__converted` 同时具备块级布局和标签背景色，背景因此占满成绩卡片主内容区，形成一条与短文案不匹配的长色条。

## 原因

- 基础样式将 `.grade-card__converted` 设置为 `display: block`。
- 页面主题样式把 `.grade-card__changed` 与 `.grade-card__converted` 合并设置了浅蓝背景。
- 后续规则只清除了 `padding`，没有清除背景，导致块级背景仍铺满可用宽度。

## 修复方案

1. 保留“已模拟”标签的浅蓝胶囊背景。
2. 将“折算 xx 分参与加权平均”恢复为无背景的辅助说明文字，仅保留主题色和现有行间距。
3. 同样处理“文字成绩仅展示，不参与加权平均”，保证两种分支视觉一致。
4. 增加静态样式回归断言，防止以后再次把折算说明与标签背景合并。

## 验收标准

- “折算 xx 分参与加权平均”不再出现横跨内容区的背景条。
- “文字成绩仅展示，不参与加权平均”也没有横向背景条。
- “已模拟”标签仍保留原有浅蓝背景。
- 文字颜色、间距和成绩卡片整体布局不发生额外变化。
- 专项测试、lint、类型检查及微信小程序构建通过。

## 实施结果

- 已拆分 `.grade-card__changed` 与 `.grade-card__converted` 的主题样式。
- “已模拟”继续使用浅蓝标签背景；两类折算说明均显式使用透明背景。
- 新增 `academic-grades-ui-smoke.ts` 并注册到 `ci:check`，防止折算说明再次与标签共用背景。
- 已通过专项测试、完整 lint、类型检查、微信小程序构建和 `git diff --check`。
