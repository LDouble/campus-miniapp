# 客户端初始化流量优化

## 目标

- 课表 GET 请求按用户和参数合并并发请求，成功结果在内存复用 30 秒。
- 私信未读数请求按用户合并并发请求，成功结果在内存复用 15 秒。
- 初始化优先请求 `/api/v1/me/bootstrap`，分发认证、签到、通知订阅和运行时配置数据。
- 聚合接口不存在、失败或分区缺失时继续调用现有独立接口，兼容服务端灰度发布。

## 一致性规则

- 只缓存成功响应；错误不缓存。
- 登录用户变化、退出登录以及相关写操作后失效缓存。
- 主动刷新绕过短时缓存。
- 缓存只保存在当前进程内，不写入持久化存储，避免跨账号泄漏旧数据。
- 保留现有 API 函数签名和页面调用方式，旧页面无需同步改造即可获得去重收益。

## 验收

- 并发调用只产生一个网络请求。
- TTL 内普通调用不再次访问网络；TTL 后重新请求。
- 失败后下一次调用立即重试。
- 用户切换后不复用前一用户的数据。
- 新聚合接口失败时现有初始化流程仍可用。
