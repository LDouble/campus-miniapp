# 今日上头：独立页面设计说明（v3）

> Feature GH-237：已确认，正在开发。

状态：根据用户确认调整为独立精选页。仅更新方案与设计图，尚未修改业务代码。

## 页面关系

**首页轮播 → 独立「今日上头」 → 帖子详情**

**独立页列表结尾 → 去社区看看新动态 → 现有第二个社区 Tab**

## 画面说明

### 01 首页入口

保留用户提供的线上首页：头像、第 4 周、签到、崂山校区、明天日历卡、完整四排服务宫格及下方运营卡。只在日历与服务之间增加紧凑「今日上头」横栏。底部首页、社区、中央发布按钮、消息、我的及角标沿用现有样式。

### 02 独立今日上头页

顶部返回键＋「今日上头」标题＋微信胶囊，下面是「看看校园里正在聊什么」简短引导。不带社区业务 Tab、板块筛选、排序切换和底部 TabBar，也没有中央发布按钮。

复用线上帖子样式：方圆角海洋头像、蓝色昵称、正文、时间与来源板块、浅蓝评论预览、操作按钮及细分隔线。图中两条帖子只为展示头部、帖子与结尾的完整结构，不代表实际内容固定为两条。

### 03 有限精选的收尾

服务端返回没有下一页后显示：

- 今天的热门就到这里
- 去社区发现更多新动态
- 蓝色主按钮「去社区看看新动态」

按钮随内容滚动，不做底部悬浮按钮。独立页可以分批加载当轮内容，但不无限拼接新榜单。网络错误显示重试，不能假装已加载到底；空榜显示「暂时没有精选动态」及去社区入口。

## 交互约束

| 元素 | 规则 |
| --- | --- |
| 首页轮播 | 固定高度约 72–80px、最多两行真实摘要；整体点击同一去向 |
| 播放 | 默认 5 秒；离屏、后台、触摸、减少动态效果时暂停 |
| 内容量 | 首页最多 20 条候选可配置；独立页当前快照最多 100 条，20 条一页，少则少展示 |
| 上下文 | 首页点中的帖子优先承接、后续去重；失效时提示而不泄露内容 |
| 详情返回 | 恢复精选页列表、快照与滚动位置 |
| 结尾跳转 | 一次性导航至现有社区校园圈最新内容，清除旧搜索/业务干扰；不新增热门模式 |
| 阅读统计 | 完整卡片与详情沿用现有有效曝光；轮播摘要只算模块曝光 |
| 数字展示 | 不展示浏览量、热度数值或名次 |

## 视觉与交付边界

使用 Ousea 主色 #2B7AEF、页面 #F5F8FC、浅蓝底 #F2F7FE、正文 #1A2333。依照线上组件校准字号和留白，不压缩服务宫格，不复刻狐友品牌，不重做现有社区页。

图为浅色高保真概念稿，非像素级交付稿。帖子、评论和轮播文案仅作设计示意；实际使用真实内容。正式实现覆盖暗色模式与无障碍，技术细节以方案文档为准。
