# 小程序：暗色模式页面首帧去白闪

## 问题

小程序支持“跟随系统 / 浅色 / 暗色”三种主题偏好。用户手动选择暗色、但微信或系统仍为浅色时，`theme.json` 会先按系统浅色主题创建原生页面容器；页面脚本随后才通过 `setBackgroundColor` 和主题 class 切换为暗色，因此每次进入新页面都会短暂显示白色背景。

## 目标

- 每个业务页面在首帧渲染前就获得用户偏好对应的原生背景色。
- 保持跟随系统、手动浅色和手动暗色三种模式一致。
- 不通过延时遮罩、淡入动画或业务页面逐个修补来隐藏闪烁。

## 方案

1. 在 App 模块加载阶段同步读取主题并设置原生背景，早于 `useLaunch` 和业务页面创建。
2. 小程序启动时调用微信 `preloadWebview`，预热首次页面导航需要的视图容器；低版本不支持时安全降级。
3. 扩展现有 `config/plugins/weapp-compat.js` 构建兼容插件，在每个非组件页面 WXML 的第一个节点注入 `page-meta`。
4. `page-meta` 使用构建插件已同步注入的 `__campusTheme`，设置页面根样式、窗口、顶部、底部、空白区域背景和下拉区域文字主题，作为最终校准而非冷启动入口。
5. 背景色从 `theme.json` 读取，避免在插件中建立另一套主题常量。
6. 扩展暗色模式 smoke，锁定启动前初始化、WebView 预热、`page-meta` 注入和背景色来源。

## 范围

- 微信小程序构建插件。
- 全局暗色主题首帧行为。
- 课表页学期入口图标的暗色适配。
- 课表课程详情浮层及内部卡片的暗色适配。
- 首页服务入口移除 CSS 图像滤镜，避免真机原生图像合成出现异常亮度反馈；视觉体系借鉴微信 WeUI 的统一线性图标、低饱和语义色与克制承载面。
- 「我的服务」入口同步采用预着色 SVG 和低明度语义底板，避免暗色模式出现浅色白块。
- 暗色模式回归断言与设计规范说明。

## 非范围

- 不重新设计暗色配色。
- 不修改业务页面结构和业务逻辑。
- 不改变主题偏好存储格式。
- 不为每个页面手工添加主题组件。

## 验收标准

1. 手动暗色偏好下，新页面生成的 WXML 首节点包含暗色首帧 `page-meta`。
2. 手动浅色偏好下首帧保持浅色。
3. 跟随系统模式继续读取微信或系统主题。
4. 页面组件不被错误注入 `page-meta`。
5. `yarn lint`、`yarn typecheck`、`yarn test:dark-mode`、`yarn test:design-tokens` 和 `yarn build:weapp` 通过。
6. 微信开发者工具中连续进入多个页面时不再出现白色过渡帧。
7. 课表左上角学期图标在暗色模式下使用可辨识的主题强调色，不保留浅色主题的深色描边。
8. 课程详情浮层、课程切换项、详情卡片、备注与操作区均使用暗色语义表面和文字色，课程色仅保留为识别强调色。
9. 首页所有服务入口的图标在浅色和暗色模式下均不使用 CSS `filter` 图像重着色，采用不超过四组的低饱和语义色与同色相承载面；颜色不作为唯一识别方式。
10. 「我的服务」在暗色模式中不保留浅色图标底板，图标与底板使用对应主题的预着色资源和语义 Token。

## 风险与控制

- `page-meta` 必须是页面第一个节点：构建插件在页面 WXML 最前方注入，并对构建产物做检查。
- 构建产物结构可能随 Taro 升级变化：保留静态 smoke 和构建后人工检查。
- 主题色漂移：从 `theme.json` 读取背景色，不复制视觉 Token。

## 实现结果

- 构建插件从 `theme.json` 读取浅色和暗色页面背景。
- 主题初始化前移到 App 模块加载阶段，并在 App `onLaunch` 时调用 `preloadWebview` 预热首次页面导航；模块求值阶段调用会早于 App 注册，不采用该时序。
- 所有非组件页面 WXML 的首节点注入主题同步的 `page-meta`，覆盖页面根样式、窗口、顶部、底部和空白区域背景。
- 修正课表页样式加载顺序导致的暗色规则失效，并适配学期 SVG 图标和课程详情浮层。
- 首页服务入口改用 SVG 自身的 SDR 颜色，不再通过 CSS `filter` 触发原生图像合成路径；按 WeUI 的低饱和语义色统一线性图标，使用学业蓝、校园青、生活琥珀和社区珊瑚四组色，OUSea 蓝仍是全局主要交互强调色。
- 「我的服务」复用同一套图标色板和暗色承载面，消除高亮白块与灰白图标。
- 构建产物检查覆盖 46 个页面，无遗漏；组件未被误注入。
- 微信开发者工具在手动暗色偏好下完成发布页验证。
