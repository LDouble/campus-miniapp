# 课程表日视图左右滑动切换日期

## 背景

日视图目前只能通过日期控件切换，单手浏览连续日期的成本较高。

## 目标

在日视图课程内容区域中，向左滑切换到下一天，向右滑切换到前一天。

## 范围

- 仅影响课程表日视图。
- 保留既有日期选择、周视图和纵向滚动行为。
- 仅在有效学期日期范围内切换；边界滑动不改变日期。

## 交互规则

1. 以横向位移超过阈值、且横向位移大于纵向位移作为有效切换手势。
2. 手势覆盖日视图工具栏下的整块内容区（日期栏、课程列表和空态）；纵向阅读和滚动不触发日期切换。
3. 切换成功后复用现有日期状态和课程数据计算，不引入额外请求。
4. 用户在动画、弹层或加载状态下操作时不得重复切换。

## 验收标准

1. 日视图向左/右滑分别切换下一天/前一天。
2. 小幅触摸和纵向滑动不切换日期。
3. 学期起止日期外不切换，且不会出现无效日期。
4. 日期标题、课程列表和空态与所选日期一致。
5. 类型检查、课程表相关回归和小程序构建通过。
