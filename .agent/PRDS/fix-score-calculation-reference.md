# OUSea小程序：按旧版成绩页修复成绩汇总计算

**Priority:** High
**Status:** Done
**Type:** Bug
**Created:** 2026-08-14
**Last Updated:** 2026-08-14

## 一、问题概述

当前成绩查询页已经实现百分制、五级制和二级制映射，以及成绩、绩点和学分的模拟编辑，但汇总计算与旧版 `/Users/liangluo/code/weouc/src/pages/score/score.jsx` 的业务口径不一致。

当前 `calculateGradeSummary` 只有在成绩、绩点和学分同时有效时，才把课程计入已选课程数、已修学分、加权平均分和平均 GPA；零分和零绩点也会进入相应平均值的分母。旧版则分别维护总学分、平均分学分和 GPA 学分，三项互不绑定。

## 二、参考规则

以旧版 `score.jsx` 的 `convertScore`、`calGPA`、`handleChange` 和 `handleInput` 为基准：

1. 已修学分
   - 课程被选中且学分为有限正数时，始终计入已修学分。
   - 是否有可识别成绩、成绩是否及格、绩点是否大于零，不影响已修学分。

2. 学分加权平均分
   - 仅折算百分制成绩大于 `0` 的已选课程参与。
   - 分子为 `折算分 × 学分` 的合计。
   - 分母仅累计上述参与平均分计算的课程学分。
   - `0` 分、未识别文字成绩或缺失成绩不进入平均分分子与分母。

3. 平均 GPA
   - 仅绩点大于 `0` 的已选课程参与。
   - 分子为 `绩点 × 学分` 的合计。
   - 分母仅累计上述参与 GPA 计算的课程学分。
   - `0` 绩点、缺失绩点不进入 GPA 分子与分母。

4. 映射与模拟
   - 保留现有百分制绩点分档以及五级制、二级制折算规则。
   - 保留成绩、绩点和学分独立模拟修改能力。
   - 模拟覆盖后仍按上述三个独立口径重新汇总。

5. 精度
   - 汇总结果按旧版口径展示三位小数。
   - 内部累加不提前截断，避免多课程累计误差。
   - 学分继续保留任意大于 `0` 的有效精度，不因展示精度丢失实际值。

## 三、已确认的现状差异

- `src/pages/academic/calculations.ts` 当前要求 `score` 和 `gradePoint` 同时存在，否则整门课程连已修学分也不统计。
- 当前使用同一个总学分作为加权平均分和 GPA 的共同分母。
- 当前 `0` 分和 `0` 绩点会进入共同分母，和旧版 `score1 > 0`、`gpa > 0` 的判断不一致。
- 当前汇总结果及页面主要显示两位小数，旧版为三位小数。
- 现有成绩文字映射与用户此前指定的 `convertScore` 已一致，无需回退。
- 新接口不提供旧版 `jd` 原始绩点字段，因此默认绩点继续使用现有校内规则映射；用户手工模拟绩点仍具有最高优先级。

## 四、实现方案

### 4.1 拆分累计项

在 `calculateGradeSummary` 中分别累计：

- `credits`：所有已选且学分有效的课程学分。
- `weightedScoreCredits`：仅折算分大于 `0` 的课程学分。
- `weightedScoreTotal`：折算分乘对应学分。
- `gpaCredits`：仅绩点大于 `0` 的课程学分。
- `weightedPointTotal`：绩点乘对应学分。

课程只要已选且学分有效，就计入 `selectedCount` 和 `credits`；平均分和 GPA 分别依据自身有效性决定是否参与。

### 4.2 零分母处理

- 没有参与平均分计算的课程时，加权平均分返回 `0`。
- 没有参与 GPA 计算的课程时，平均 GPA 返回 `0`。
- 即使两个平均值均为 `0`，已修学分和已选课程数仍按有效选择保留。

### 4.3 页面展示

- 汇总卡片中的加权平均分与平均 GPA 使用三位小数。
- 已修学分使用现有自适应格式，保留小于 `0.01` 的正学分展示能力；不强制截断到三位。
- 课程卡片及模拟编辑交互保持不变。

## 六、测试要求

### 自动测试

- 及格课程正常参与总学分、加权平均分与 GPA。
- `0` 分、`0` 绩点课程计入已修学分，但不进入两个平均值的分母。
- 未识别文字成绩计入已修学分，但不进入两个平均值。
- 仅成绩有效、绩点缺失时，只参与加权平均分。
- 仅绩点有效、成绩缺失时，只参与平均 GPA。
- 模拟成绩、绩点和学分分别改变对应汇总结果。
- 极小学分仍完整保留。
- 执行 `yarn test:academic-calculations`、`yarn typecheck`、`yarn lint`、`yarn build:weapp` 和 `git diff --check`。

### 手工验收

- 勾选不及格课程后，已修学分增加，但加权平均分和平均 GPA 不被零值拉低。
- 勾选未知文字成绩后，已修学分增加，两个平均值不变。
- 修改模拟分数时，仅按有效折算分更新加权平均分。
- 修改模拟绩点时，仅按有效绩点更新平均 GPA。
- 汇总平均分和平均 GPA 显示三位小数。

- 汇总结果与旧版 `score.jsx` 的计算口径一致。
- 现有百分制、五级制、二级制映射与模拟编辑能力不回归。
- 自动检查和小程序生产构建全部通过。
