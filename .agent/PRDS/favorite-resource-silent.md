# 收藏错误提示修复 PRD

## 背景

帖子处于审核中或已取消时，后端返回资源不存在属于预期业务状态。当前小程序收藏调用链将该响应统一作为错误提示，造成用户看到不必要的“资源不存在”。

## 目标

- 对资源不存在业务错误不展示错误提示。
- 正常资源继续按原逻辑更新收藏状态。
- 网络、鉴权、限流和系统错误继续提示用户。

## 范围

- 小程序收藏接口调用及其统一错误处理。
- 相关收藏入口的回归测试。

## 非目标

- 不修改后端接口、错误码和收藏数据模型。

## 验收标准

1. 审核中或已取消帖子点击收藏时不弹资源不存在提示。
2. 合法资源收藏成功且 UI 状态正确。
3. 非资源不存在错误仍保留原有提示。
4. 通过 lint、typecheck、相关测试和小程序构建。

## 实施方案

定位收藏请求的统一错误出口，基于稳定的业务错误码优先判断资源不存在；仅对该错误返回静默结果，避免依赖易变的错误文案。补充成功、目标业务错误和其他错误的测试。
