# 小程序：社区动态卡片时尚化重设计

**Priority:** High
**Status:** Done
**Type:** Enhancement
**Created:** 2026-07-26
**Last Updated:** 2026-07-26

## 概述

重新设计社区 Tab 的动态内容卡片。保留当前社区板块、搜索、分页、点赞、评论、分享和详情跳转逻辑，只升级内容卡片的视觉语言与触控体验。

设计调整为“内容优先的校园生活流”：借鉴小红书信息流的弱容器、轻分隔、图标化互动和紧凑作者信息，但不复刻品牌配色与具体界面。正文和图片承担主要视觉重量，校园紫蓝色只用于当前板块和点赞等必要状态。

## 用户故事

**作为** 浏览校园社区的学生

**我希望** 一眼分辨作者、板块、正文、图片和互动数据

**从而** 更轻松地扫读动态，并愿意进入详情、点赞或评论

## 当前问题

- 首轮改版叠加了卡片边框、圆角、阴影、顶部色带、板块胶囊和三块操作按钮，装饰层级过多。
- 每条动态像一个独立功能面板，削弱了社区内容流应有的连续浏览感。
- 板块和成员编号都使用胶囊，标签感强于内容本身。
- 点赞、评论、分享虽然有图标，但仍被按钮框包围，不够轻巧。
- 多套动态卡片色调造成内容列表过于花哨，不利于快速扫读。

## 视觉方案

### 卡片外观

- 移除整卡边框、大圆角、阴影、渐变光晕和顶部色带。
- 使用白色内容底、充足留白和底部细分隔线形成连续信息流。
- 不再根据 `section_id` 生成整卡主题色，避免同一信息流中色彩跳动。
- 正文按压只使用轻微透明度，动画控制在 150–200ms。

### 作者信息

- 头像改为简洁圆形身份标识，不使用在线状态装饰。
- 作者名称与成员编号合并为一行纯文字信息，不再使用编号胶囊。
- 发布时间保持次级文字。
- 板块名称使用 `#` 话题语义和纯文字表达，不再使用胶囊背景。

### 正文内容

- 标题字号、字重与行距提高，形成编辑流标题感，最多显示两行。
- 正文使用高对比灰色、舒适行距，最多显示四行。
- 无标题动态仍保持自然间距，不产生空白占位。
- 整个正文和图片区域可点击进入详情。

### 图片宫格

- 单图使用更大的横向封面比例。
- 两图保持对称双列。
- 三图使用主图加双副图的杂志式布局，避免三张窄图平均切割。
- 超过三张时在第三张图片上显示 `+N` 遮罩。
- 保持 `aspectFill` 与 `lazyLoad`，不增加外部图片或依赖。

### 互动区

- 点赞、评论、分享只显示统一线性图标；点赞和评论在图标旁显示数字。
- 移除互动按钮的边框、底色、圆角块和行为文字。
- 点赞态通过实心心形图标和强调色表达。
- 可见图标保持轻巧，但隐形触控目标高度不少于 88rpx、宽度不少于 88rpx。
- 使用 Taro `View.hoverClass` 提供真实小程序按压反馈。

## 组件结构

```text
动态卡片
├── 作者区
│   ├── 圆形头像
│   ├── 作者名 / 成员编号 / 发布时间
│   └── 服务端板块话题文本
├── 可点击正文区
│   ├── 标题
│   ├── 正文摘要
│   └── 图片宫格 / 剩余数量
└── 互动区
    ├── 点赞图标与数量
    ├── 评论图标与数量
    └── 分享图标
```

## 业务与数据约束

- 不修改后端接口、OpenAPI 或数据库。
- 不修改社区板块的服务端获取逻辑。
- 不硬编码板块名称、板块 ID、作者昵称或互动数字。
- 保持 `onToggleLike`、`onOpen` 和现有分享入口行为。
- 只展示接口已经返回的前三张图片，剩余数量由 `post.images.length` 计算。
- 公开列表仍只展示后端返回的已发布动态。

## 验收标准

1. 社区动态呈现为连续内容流，整卡无边框、无阴影、无装饰性色块。
2. 作者、时间、板块、标题、正文和互动数字在 375px 等效宽度下清晰可读。
3. 板块名称继续来自服务端，不包含板块名称或 ID 硬编码。
4. 单图、双图、三图和三张以上图片布局均不溢出；三张以上显示剩余数量。
5. 点赞、评论、分享以图标为主要表达，无胶囊和按钮外框，触控目标满足最小尺寸。
6. 点赞状态更新、详情跳转、评论入口和分享入口不回归。
7. 无图片、无标题、长标题、长正文和长板块名均能正确排版。
8. TypeScript 检查和微信小程序构建通过。
9. 微信开发者工具真实模拟器截图通过人工视觉验收，网络请求无新增失败，控制台无未处理异常。
10. `git diff --check` 通过。

## 第三轮方向调整：轻彩化

- 保留第二轮已经确认的弱容器、扁平筛选和图标化结构。
- 将纯黑、纯白调整为暖白、炭灰与淡紫灰，降低工具感和生硬感。
- 色彩仅用于头像、话题、选中状态、发布入口与点赞反馈，不新增边框、胶囊和装饰色块。
- 头像颜色由服务端 `section_id` 稳定派生低饱和紫、青、玫瑰和暖棕，不硬编码板块名称或 ID。

## 第四轮最终视觉基准：校园清新服务卡片

- 移动端卡片式设计：每条动态使用独立轻量卡片，但不使用粗边框和卡片内按钮框。
- 轻量化新拟态：采用双层柔和阴影与极浅内高光，避免明显凸起、凹陷和低对比文字。
- 柔和渐变与半玻璃拟态：页面使用淡蓝紫渐变，卡片使用高透明度暖白背景与轻微模糊。
- 校园清新服务平台：以紫蓝为主识别色，搭配低饱和青绿、玫瑰和暖棕头像色。
- 保留图标化点赞、评论、分享和扁平文字筛选，避免重新堆叠胶囊。
