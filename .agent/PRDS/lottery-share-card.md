# 抽奖分享卡片优化

**状态：** 已实施，模拟器验证通过，待真机分享验收
**日期：** 2026-09-12

## 目标与范围

优化微信聊天中抽奖详情的分享标题和缩略图，与最新抽奖页橙白视觉一致。仅涉及小程序，不修改后台契约和奖励规则。

## 方案

- 分享标题优先表达活动和邀请意图，如“邀你参与校园抽奖｜活动名称”，避免使用必中奖、虚构奖品或夸大价值。
- 生成专属卡片图：品牌/活动标签、活动标题、主要奖品图片和名称、奖品总份数、开奖方式及简短参与提示；布局按微信分享缩略图裁切验证。
- 奖品图优先取真实奖品，缺图使用现有礼盒素材。多奖品突出主要奖品并标注奖品种类数；长标题自动换行或省略。
- 卡片展示活动截止日期或真实状态，不把实时倒计时烘焙进图片；已结束活动不显示正在参与等误导性提示。
- 异步预生成并缓存图片；生成失败或图片未就绪使用稳定默认分享图，不阻塞分享。
- 分享路径继续携带活动 id 和已有 share_token，不把生成图片视为有效分享或增加奖励次数。
- 不将个人微信号、登录凭据、分享 token 绘制在图片内。朋友圈单独核对缩略图裁切。

- 页面预生成并复用当前数据对应图片，绘制串行化，旧请求不会覆盖新活动数据；远程图片限时失败兜底，不修改分享归因逻辑。
