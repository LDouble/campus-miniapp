# Campus Miniapp: 教务密码中文符号转换重试

**Priority:** High
**Status:** Done
**Type:** Enhancement
**Created:** 2026-08-16
**Last Updated:** 2026-08-16

## 问题

用户可能在中文输入法下输入密码符号，例如 `！`、`？`、`，`、`。`。教务系统会把这些符号视为与英文半角符号不同的字符，当前页面只会提示密码错误，用户不容易发现输入法差异。

## 交互方案

1. 仅当服务端返回 `invalid_academic_credentials` 时检查密码，不在输入过程中主动修改。
2. 检测全角 ASCII、中文标点及其明确对应的英文半角符号。
3. 检测到可转换符号后显示确认弹窗：
   - 标题：`密码符号可能输错了`
   - 内容：`检测到密码中含有中文输入法符号，可能与实际密码不一致。是否仅转换为对应的英文半角符号，并重新验证？`
   - 确认：`转换重试`
   - 取消：`保持原样`
4. 用户确认后更新输入框密码，并使用转换结果自动重试一次。
5. 自动重试成功时保存转换后的密码；失败时沿用现有密码错误、过期、限制、验证码等处理。
6. 用户取消时仅关闭弹窗，不修改密码、不自动重试，也不更新被拒绝凭据状态。

## 安全与边界

- 不在弹窗、日志、错误上报或测试输出中展示原密码或转换后密码。
- 不处理普通中文文字，只转换符号和全角 ASCII 字符。
- 不对网络错误、服务不可用、密码过期、账号限制或验证码错误触发转换。
- 每次用户主动提交最多自动重试一次，避免循环请求和账号风控。

- `scripts/academic-credential-repeat-smoke.ts`：符号映射、错误码保护、单次重试和敏感信息回归断言。

## 验收标准

- 输入包含中文/全角符号的错误密码时出现确认弹窗。
- 确认后转换输入框内容并自动提交一次；成功后保存转换后的密码。
- 取消后密码和页面状态保持原样且不再次请求。
- 不含可转换符号的密码错误沿用原提示。
- 非密码错误不出现转换弹窗。
- 专项测试、lint、类型检查和微信小程序构建通过。

## 实施结果

- 新增独立纯函数，显式转换全角 ASCII、常见中文标点以及中文输入法的省略号、破折号组合；普通中文文字保持不变。
- 仅在首次请求明确返回 `invalid_academic_credentials` 时展示提示，每次主动提交最多自动重试一次。
- 用户选择“转换重试”后更新输入框并提交转换结果；选择“保持原样”或关闭弹窗时直接结束，不修改密码、不记录错误凭据、不再次请求。
- 转换后仍失败时，按转换后的实际提交值沿用密码错误、密码过期、账号限制和验证码冷却处理。
- 已通过 `yarn test:academic-credential-repeat`、完整 `yarn lint`、`yarn typecheck`、`yarn build:weapp` 与 `git diff --check`。
