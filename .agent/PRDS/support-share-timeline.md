# Campus Miniapp: 支持分享到朋友圈

**Priority:** High
**Status:** Done
**Type:** Feature
**Created:** 2026-08-16
**Last Updated:** 2026-08-16

## 背景

项目已经通过统一的 `useCampusShare` 支持微信好友分享，覆盖首页、服务、社区、帖子/话题、闲置、跑腿、拼车、校车、社团、通知、校历、空教室和课程资料等页面，但尚未注册 `useShareTimeline`，页面配置中也没有开启 `enableShareTimeline`，因此微信右上角菜单不提供“分享到朋友圈”。

## 目标

1. 所有已经调用 `useCampusShare` 的页面同时支持分享到朋友圈。
2. 朋友圈标题和图片复用好友分享数据，保持产品文案一致。
3. 朋友圈 query 与好友分享路径参数一致，详情页从朋友圈进入后仍能打开对应内容。
4. 不扩大分享范围，不给尚未定义分享内容的页面开启朋友圈。

## 技术方案

1. 在统一分享层同时注册 `useShareAppMessage` 和 `useShareTimeline`。
2. 新增纯函数构建朋友圈返回值：
   - `title`：复用现有清洗、兜底和 36 字限制。
   - `query`：从好友分享的完整 path 中提取并保留 URL 编码后的查询串。
   - `imageUrl`：仅在存在非空图片时返回。
3. 朋友圈回调没有按钮事件，统一以菜单事件调用分享工厂；社区列表页面因此分享当前社区分区，而不是某张帖子卡片。
4. 给全部 17 个已使用 `useCampusShare` 的页面配置增加 `enableShareTimeline: true`，保留原有 `enableShareAppMessage: true`。
5. 扩展现有 `share-smoke`，覆盖空 query、已有 path query、追加 query、图片清洗、标题截断、统一 Hook 和页面配置完整性。

## 页面范围

- 首页、全部服务、校历、空教室、课程资料。
- 社区首页、社区帖子详情、话题页。
- 闲置详情、跑腿详情、拼车详情。
- 校车首页及详情。
- 社团首页及详情。
- 全校通知首页及详情。

## 平台限制

- 朋友圈分享由微信右上角菜单触发，不是页面内 `openType='share'` 按钮。
- 微信朋友圈返回值不支持自定义页面 path，只能携带当前页面的 query；因此统一分享层会从现有分享 path 中提取 query。
- 按当前 Taro 官方文档，该能力仅面向微信小程序，需基础库 2.11.3 及以上，并仍标注为 Beta/Android 支持；不承诺其他小程序平台或微信客户端均展示入口。

## 安全与边界

- 不把登录态、密码、联系方式或其他额外状态加入 query。
- 只复用原有公开分享参数，不新增数据请求。
- 审核中或不应公开的图片仍沿用各页面现有 `imageUrl` 判断，不绕过业务可见性规则。

## 验收标准

- 已支持好友分享的 17 个页面均配置 `enableShareTimeline: true`。
- 微信右上角菜单可出现“分享到朋友圈”，并返回正确标题、query 和可选图片。
- 帖子、话题、闲置、跑腿和拼车详情从朋友圈进入时保留对应 id。
- 社区列表从朋友圈分享时保留当前分区，不错误绑定某张卡片。
- 原有“分享给好友”和页面内分享按钮行为不变。
- 分享专项测试、lint、类型检查及微信小程序构建通过。

## 实施结果

- 统一 `useCampusShare` 已同时注册好友分享和朋友圈分享生命周期。
- 新增朋友圈消息构建纯函数，复用标题清洗、36 字截断和图片清洗，并从好友分享 path 中安全提取 URL 编码后的 query。
- 已给全部 17 个现有分享页面开启 `enableShareTimeline: true`，未扩大到其他页面。
- 社区列表的朋友圈分享按菜单事件生成当前分区参数，不会误用帖子卡片的按钮数据。
- 分享专项测试会动态扫描所有 `useCampusShare` 页面，要求好友分享和朋友圈配置同时存在。
- 已通过 `yarn test:share`、目标文件 ESLint、完整 `yarn lint`、`yarn typecheck`、`yarn build:weapp` 和 `git diff --check`。
- 构建产物 `dist/full` 已核对，17 个目标页面均包含朋友圈分享配置。
