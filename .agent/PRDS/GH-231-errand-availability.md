# 跑腿可接单识别与角色状态文案

## 已确认需求

- 已送达：发布者展示“待确认完成”；跑腿员展示“已送达，等待对方确认”；其他用户展示“已送达”。
- 清晰区分可接单任务与非可接单任务。
- 大厅仅可接单任务优先，其他任务随后；各组按创建时间和 ID 倒序。游客首页缓存仅复用第一页，后续页实时查询，避免截止时间变化造成跨页排序陈旧。

## 实施边界

后端在分页前排序；资格为待接单、审核通过、未截止、非本人发布。游客按任务资格展示，操作沿用登录与认证要求。保留已接单、送达和完成历史，不改变状态流转及支付。前端列表和详情共享展示规则。

## 验收

验证不同角色的送达文案、截止边界、自发布任务、审核中任务、跨页排序以及缓存截止失效。执行后端目标测试和小程序仓库要求的检查。按用户要求提交 PR；不上传或发布体验版。

## 标签配色

可接单使用绿色；已接单和配送中使用蓝色；已送达、待确认和审核中使用橙色；审核驳回使用红色；待接单（本人发布）、已完成、已截止使用灰色。沿用全局语义变量适配暗色模式。
