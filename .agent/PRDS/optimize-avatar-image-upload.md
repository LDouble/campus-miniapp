# 头像图片上传优化

## 背景

当前头像会裁剪为 1:1，并使用 `quality: 82` 二次压缩，但没有限制像素尺寸。高分辨率头像即使文件体积不大，仍会增加客户端解码内存；PNG 的质量参数不会生效。

## 目标

- 头像保持 1:1 裁剪。
- 头像最长边最多 512 px，不放大小于 512 px 的图片。
- JPEG 压缩质量设为 80；PNG 同样执行尺寸缩小，但不依赖质量参数控制体积。
- 普通社区和二手图片继续使用现有质量 82 规则，不改变像素尺寸。
- 压缩 API 不可用时继续使用当前图片，并由既有格式、体积和服务端真实性校验兜底。

## 验收标准

1. 头像调用图片压缩时设置不超过 512 px 的等比宽高和质量 80。
2. 小于 512 px 的头像不被放大。
3. 非头像图片保持质量 82，且不强制缩放到 512 px。
4. 上传文件大小和尺寸来自最终压缩文件。
5. 媒体 smoke、TypeScript 类型检查和微信小程序构建通过。

## 非目标

- 不修改后端 5 MiB、8192 px 和 4000 万像素的安全上限。
- 不在本次强制把 PNG 转换为 JPEG。
- 不修改历史头像对象。
