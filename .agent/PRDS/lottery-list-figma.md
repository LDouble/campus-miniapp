# 抽奖列表视觉重构

**状态：** 已确认并实施，待模拟器视觉验收

## 实施记录

- 列表使用方形封面、标题与真实状态、认证标签、奖品摘要、分隔线及截止时间/详情入口。
- 移除无依据的分享奖励导航承诺；未加入筛选、TabBar、虚构人数与预约能力。
- 缺图/失败使用现有礼盒，保留分页、刷新和错误重试；保留上一轮未提交分享卡片改动。
**日期：** 2026-09-12

## 范围

参考 Figma `xf5G1hBBYt03E3sTZ2rmBV / 3753:208`，重构抽奖活动列表。用户明确不需要筛选项和底部 TabBar，不新增这些区域，也不修改其他页面的全局 TabBar。

## 实现方案

- 浅灰页面底色、白色圆角活动卡片、左侧方形封面、右侧活动标题及状态标签，下方分隔线与截止时间、详情入口。
- 保留导航返回；移除稿中状态筛选与快捷筛选。顶部公告只展示有真实依据的信息，不硬编码“今日新增”或测试活动内容。
- 活动状态依据真实状态、开始和截止时间区分进行中、即将开始、等待开奖、结果公布、取消；不展示虚构参与人数或进度。
- 奖品展示真实名称和份数，多奖品摘要注明其余种类，进入详情查看全部。
- 主入口跳转活动详情，不从列表直接领取抽奖码；未实现的人数开奖、预约提醒、品牌分类和主办方信息不模拟。
- 封面优先后台配置，无图或加载失败时复用礼盒素材；长标题两行省略，窄屏无横向溢出。
- 保留列表分页、下拉刷新、加载、错误重试、空态、暗色、安全区和减少动态效果。
- 不覆盖上一轮尚未提交的分享卡片改动；只修改列表及对应规范、测试。预览直接从 Feature 工作区构建，不合并 Release。

## 验收

Lint、类型检查、抽奖/设计令牌/暗色/字体测试及小程序构建通过；模拟器核对列表视觉、状态、无图和活动跳转，确认无筛选栏及底部 TabBar。无后端契约变化，不发布线上。
