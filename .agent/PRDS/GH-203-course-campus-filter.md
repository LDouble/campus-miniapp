# 小程序：蹭课学分与开课校区筛选

**Priority:** Medium
**Status:** In Progress
**Type:** Enhancement
**Created:** 2026-09-06
**Last Updated:** 2026-09-06

## Overview

让同学在蹭课检索时更快判断课程负担和上课地点：课程卡片明确呈现学分，更多筛选提供由当前学历层次与学期课程目录动态返回的开课校区；同时让通识课查询列表在深色模式下保持清晰层级。

## User Story

**As a** 准备旁听或模拟选课的同学
**I want** 在课程卡片中直接看到学分，并按开课校区筛选课程
**So that** 我能更快判断课程安排是否适合自己。

## Context

课程目录响应和卡片已具备可选 `credits` 字段，但当前标题行中的弱标签容易被忽略；目录源数据没有学分时不应伪造数值。课程搜索接口已经接受 `campus` 参数并由后端筛选，但小程序缺少当前学历层次、学期的有效校区选项来源。

## Implementation Overview

- 将课程学分从标题附属标签调整为卡片内明确、紧凑的课程事实信息；只在服务端返回有效学分时展示。
- 后端新增课程目录校区选项接口，按学历层次和学期查询当前有效课程快照中的去重校区；不写死校区名单。
- 小程序基于该接口在“更多筛选”展示开课校区选择器，将 `campus` 与课程、教师、星期、节次、类别一起传给已有课程搜索接口。
- 切换学历层次或学期时刷新选项；当已选校区不再存在时自动清空，避免无结果的失效条件。
- 后端 OpenAPI 契约生成后，小程序同步生成客户端类型；两个 PR 互相链接，并在小程序 PR 标注依赖的后端契约提交。

## Features / Requirements

1. **课程学分展示**
   - 有效学分以“学分 2.0”形式展示在课程卡片的事实信息区。
   - 不占用课程名、类别、教师和班级说明的主信息空间。
   - 学分为空时不显示占位文案或空白槽位。

2. **开课校区选项接口**
   - 新增只读 member 接口，输入学历层次和学期，返回当前有效课程目录的去重校区列表。
   - 返回结果只包含非空、规范化的校区文本，稳定排序。
   - 不新增表结构或迁移；复用现有课程目录有效批次和索引范围。

3. **开课校区筛选**
   - 在“更多筛选”中增加“开课校区”Picker，默认“全部校区”。
   - 已选校区增加到筛选计数、查询参数、提交态和清空逻辑。
   - 校区与课程关键词、教师、星期、节次、类别取交集。
   - 选项加载中或失败时有明确、紧凑的可读状态。

4. **通识课查询深色模式**
   - 通识模块查询页面的页面底色、卡片、输入框、模块选项、提示区和结果列表都使用语义色 Token。
   - 深色模式下正文、辅助文字、描边和蓝色选中态均保持可读；不能遗留亮色白底或低对比度灰字。

## Files to Modify

- 后端 `api/modules/academic_course_catalog.yaml`、对应 handler / application / repository / MySQL 实现和测试 - 新增校区选项契约及查询。
- 后端生成产物 - 仅通过 `make generate` 更新 OpenAPI、adapter 和 DTO。
- 小程序 `src/api/course-catalog.ts`、生成客户端类型 - 调用校区选项接口并提交 `campus` 搜索条件。
- 小程序 `src/pages/academic/course-catalog/index.tsx`、`index.scss` - 学分事实项、校区选择器、状态和筛选同步。
- 小程序 `src/pages/academic/general-education/index.scss` - 修复通识课查询列表的深色模式语义色适配。
- 相关 smoke tests - 覆盖学分显示、校区筛选参数、选项刷新和清空。

## API Endpoints

- `GET /api/v1/course-catalog/campuses` - 查询指定学历层次和学期的有效开课校区选项。
- `GET /api/v1/course-catalog/courses?campus=...` - 使用已有兼容参数；小程序新增提交。

## Acceptance Criteria

- 有学分的课程卡片清晰显示“学分 N”，无学分的卡片不留空白。
- 更多筛选可选择“开课校区”，默认不筛选。
- 校区选项来自当前学历层次和学期的实际课程目录，切换范围后不会保留失效选择。
- 所有筛选条件按交集生效，并能通过清空恢复默认。
- 通识课查询页面在深色模式下不存在亮色卡片、输入区或不可读的正文/辅助文本。
- 后端契约、目标包测试、生成校验和小程序 lint、类型检查、设计规范、暗色模式、小程序构建均通过。

## Risks / Considerations

- 旧课程目录快照的 `credits` 可能为空；本功能只优化展示，不回填或猜测历史数据。
- 校区筛选需以课程条目的开课校区为准；不能混用排课地点或用户当前校区。
- 后端契约应先合并，前端 PR 在未合并前必须明确依赖该契约提交。
