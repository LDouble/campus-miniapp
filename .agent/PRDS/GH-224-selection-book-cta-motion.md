# 小程序：选课结果求购课本入口引导提示

**Issue:** [#224](https://github.com/LDouble/campus-miniapp/issues/224)
**Priority:** Medium
**Status:** Done
**Type:** Enhancement
**Created:** 2026-09-11
**Last Updated:** 2026-09-11

## 背景

选课结果详情已经提供“求购课本”入口，并能携带课程信息进入校园二手搜索，但用户必须先打开课程卡片才能发现。需要把操作前置到列表，在保持课程上下文的同时缩短操作路径。

## 用户故事

**作为** 刚确认选课结果的学生  
**我想** 得到一次清晰但不打扰的提示  
**以便** 直接去校园二手寻找对应课程教材。

## 需求

1. 将“求购课本”从详情操作区移到每门已选课程的列表卡片底部，未选或待确认课程不展示。
2. 点击“求购课本”直接按对应课程进入校园二手搜索，并阻止点击冒泡，不额外打开课程详情。
3. 每次进入选课结果页时，在第一门已选课程的“求购课本”按钮附近展示轻量气泡，文案为“去闲置找二手书”。
4. 气泡展示 3 秒后自动消失，不记录本地频控状态，也不要求用户手动关闭。
5. 气泡动效使用 `opacity` 和 `transform` 等合成属性，不修改宽高，不造成布局抖动或持续闪烁。
6. 系统启用 `prefers-reduced-motion: reduce` 时禁用气泡动效，但仍静态展示 3 秒。
7. 浅色与暗色主题下保持气泡、按钮文字、背景和边界清晰，并提供可访问名称。
8. 当前学期存在已选课程时，在课程汇总卡下方展示“一键求购本学期教材（N 门）”。
9. 点击一键求购后，把全部已选课程名称和可用课程代码写入一条合并求购描述，并打开现有求购发布表单。
10. 合并求购自动带入学期与课程数量，但不自动提交；用户仍需确认预算、联系方式和最终内容。

## 实现概述

- 每次进入选课结果页时重新启动 3 秒计时器，页面隐藏、数据刷新或再次进入时安全清理旧计时器。
- 在已选课程卡片底部渲染可直接操作的“求购课本”，并在第一门已选课程的按钮附近渲染轻量气泡。
- 从当前学期记录派生全部已选课程，为页面级一键求购生成有序课程清单与概括性课程标题，复用现有求购预填和发布流程。
- 在教务页公共样式中增加完整的 3 秒出现—停留—淡出关键帧，并将其纳入现有 reduced-motion 降级规则。
- 扩展教务页面 smoke test，断言提示文案、3 秒时长、重复展示入口和 reduced-motion 禁用规则。
- 在教务页面设计覆盖文档中记录课程关联入口的动效边界。

## 验收标准

- 每门已选课程卡片都直接展示“求购课本”，点击后不打开详情并按该课程进入校园二手搜索。
- 页面显示“一键求购本学期教材（N 门）”，点击后发布表单包含全部已选课程清单、当前学期和求购意图。
- 一键求购不会直接创建或提交帖子，用户必须确认预算与联系方式。
- 每次进入选课结果页时，第一门已选课程按钮附近出现引导气泡。
- 气泡展示 3 秒后自动消失；再次进入页面时重新展示。
- 气泡不循环闪烁；开启减少动态效果后静态展示 3 秒。
- 点击按钮仍进入校园二手，并按当前课程预填搜索条件。
- `yarn lint`、`yarn typecheck`、`yarn test:design-tokens`、`yarn test:typography`、`yarn test:dark-mode`、教务专项 smoke test 与 `yarn build:weapp` 通过。

## 风险

- 底部 Sheet 每次重新挂载都可能重新播放 CSS 动效，因此必须限制播放次数与时长，避免频繁开关详情时产生强打扰。
- 微信小程序对部分 CSS 动画细节的支持与浏览器不同，实现应保持简单并以构建及模拟器效果为准。
