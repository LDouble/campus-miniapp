# Campus Miniapp: 优化社区列表与评论性能

**Priority:** High
**Status:** Done
**Type:** Enhancement
**Created:** 2026-08-16
**Last Updated:** 2026-08-16

## Overview

在不改变社区数据语义和现有视觉风格的前提下，减少信息流与评论组件的无效渲染、一次性节点数量和 GPU 合成负担，改善搜索输入、点赞、键盘升降、长评论线程和图片列表滚动时的流畅度。

## User Story

**As a** 使用校园社区的小程序用户

**I want** 列表滚动、点赞、搜索和评论输入保持稳定流畅
**So that** 浏览图片动态和参与讨论时不会卡顿或被过度动画打断

## Context

代码与运行时审查发现：

- 话题页一次请求并挂载 50 张完整卡片，同时触发入场动画。
- 主信息流搜索框每次输入、点赞更新会使整列卡片重新渲染，未利用未变帖子对象的引用稳定性。
- 评论输入内容和键盘高度变化会让完整评论树重新计算；回复树构建及昵称查找在长线程下存在重复遍历。
- 评论与列表分页持续累积节点；评论分页去重仍使用重复线性扫描。
- 现有列表图片已懒加载并预留固定高度，点赞动画已使用 `transform` 且支持减弱动效，应保留。

## Implementation Overview

采用低风险、可回归的分层优化：稳定帖子卡片组件边界和回调，降低话题页单次渲染规模，缓存评论派生数据，并把卡片入场限制在主信息流前 4 张。本次不扩展视觉样式或增加批量动画。

## Features / Requirements

1. **社区卡片渲染隔离**
   - 使用 `React.memo` 包装纯帖子卡片。
   - 主信息流、话题页和公开主页向卡片传递稳定回调。
   - 搜索输入或单帖点赞时，未变化的帖子卡片不重新渲染。

2. **控制列表规模与入场动画**
   - 话题页首批改为 20 条，并提供分页加载更多。
   - 仅主信息流首屏前 4 张卡片使用入场动画；分页追加、运营推荐、话题页和个人主页不批量播放。
   - 保留图片懒加载及 1/2/3 图固定占位。

3. **评论计算与请求优化**
   - 缓存每条根评论的回复树及成员昵称索引，避免输入和键盘事件重复构建。
   - 评论分页使用 `Set` 去重。
   - 直接回复根评论时不预拉完整线程；仅在确有隐藏子回复时加载。
   - 增加必要的请求时序保护和定时器清理，避免旧响应与卸载后更新。
   - 优先将高频输入/键盘状态与评论列表渲染边界隔离；若拆分风险过高，至少保证派生树不重新计算。

## 本次范围外

- 固定导航、弹幕模糊和骨架动画成本治理留作后续独立任务。
- 其他可点击 `View` 的可访问性补齐留作后续独立任务；本次仅为新增的“加载更多”补齐语义。

## Libraries/Dependencies

- Taro 4.1.11：沿用现有组件、图片懒加载和小程序构建能力，不增加依赖。
- React：使用现有 `memo`、`useCallback`、`useMemo`、`useRef`，不引入状态库或虚拟列表依赖。

## Technical Considerations

- Taro 小程序最终会生成 WXML/WXSS 与 setData 更新，优化重点是减少稳定卡片子树和长评论树进入差异计算。
- 不直接引入通用 Web 虚拟列表，避免与小程序页面滚动、分享按钮和原生输入组件产生兼容风险。
- 话题页分页必须保持去重、下拉刷新和点赞更新语义。
- 评论优化不得改变回复层级、审核状态、删除动画和键盘遮罩行为。
- 不改变现有动画时长和属性，仅限制哪些卡片获得入场动画类名。

## Design/UX Considerations

- 延续现有蓝色校园社区视觉，不采用审查工具给出的全局换色或字体替换建议。
- 保留点赞反馈和少量首屏入场，避免所有卡片同时运动。
- 异步内容继续预留高度，避免 skeleton 切换和图片加载推挤页面。

## Testing Requirements

### Unit / Structural Tests

- 验证帖子卡片使用 memo，主列表回调稳定且仅前 4 项显式入场。
- 验证话题页每页 20 条、分页追加与去重。
- 验证评论派生树缓存、Set 去重、请求时序与定时器清理。

### Integration Tests

- 搜索框连续输入时列表内容和图片保持稳定。
- 点赞只更新目标卡片，分享与详情快照导航不受影响。
- 评论键盘出现、关闭、回复与取消不闪动，长线程仍正确展示。
- 话题页加载更多后无重复帖子，刷新回到第一页。

### Manual Testing Checklist

- 社区信息流快速滚动无明显掉帧。
- 带图片帖子点赞、进入详情和评论输入稳定。
- 话题页首屏加载更轻，查看更多反馈清晰。
- 公开主页社区列表交互正常。
- 话题页、个人主页和分页追加内容不批量播放入场动画。
