# Miniapp：修复蹭课页深色模式

## 1. 背景

蹭课检索页新增了独立的检索、说明、课程卡片和模拟选课操作，但页面专属样式没有完全接入全局深色主题覆盖。系统切换到深色模式后，部分白色表面、浅色边框、输入占位和状态文字与背景对比失衡，影响课程浏览和操作识别。

## 2. 目标

在不改变蹭课检索业务和布局的前提下，补齐该页面所有状态的深色语义色，保证搜索、筛选、课程列表、我的蹭课、说明和加载状态在深色模式下清晰可用。

## 3. 方案

- 盘点 `course-catalog` 页面 SCSS 中的浅色固定值和组件状态。
- 在页面最终样式层补充 `.campus-theme--dark` 语义覆盖，优先复用 `--campus-*` / `--ousea-*` 令牌。
- 课程色、主按钮、危险操作和说明提示分别保持既有业务语义，不使用全局反色或滤镜。
- 为深色模式 smoke test 增加蹭课页关键选择器断言，避免后续新增浅色固定值遗漏适配。

## 4. 非目标

- 不改变课程搜索参数、分页、蹭课/模拟选课数据和接口契约。
- 不修改全局主题基础 Token。
- 不调整蹭课页浅色模式布局和交互。

## 5. 验收

1. 深色模式下页面背景与卡片表面有清晰层级。
2. 搜索框、学期选项、更多筛选、课程卡片及课程状态文字均可读。
3. 说明卡、加载态、空态、错误态和底部/浮层操作没有浅色残留。
4. 浅色模式保持原有视觉与交互。
5. 通过 `yarn test:dark-mode`、`yarn lint`、`yarn typecheck` 和 `yarn build:weapp`。
