# 小程序：猫猫列表返回与选课弹层闪动修复

**Priority:** High
**Status:** In Progress
**Type:** Bug
**Created:** 2026-09-12
**Last Updated:** 2026-09-12

## 目标与范围

仅修复当前小程序两个交互的内容闪现与滚动跳动，不改后端、接口、权限或视觉设计；用户明确继续当前分支。

## 代码调查

- 猫猫列表 `src/pages/cat-atlas/catalog-list.tsx` 每次 useDidShow 无条件重新 load，非追加请求设置 loading，渲染替换整个列表。图片重新挂载后从默认比例变为真实比例，触发二次布局。
- 选课结果 `src/pages/academic/selection/index.tsx` 打开弹层时给页面添加 academic-page--locked；共享样式将长页面压缩为 100vh 并隐藏溢出，关闭时恢复。存在滚动位置被截断的确定性风险，实际设备闪动仍需复现验证。
- 已按 Taro Documentation 与 Context7 核对 useDidShow、View catchMove 和 ScrollView 官方文档。

## 实施方案

- 区分猫猫首屏加载、筛选/搜索、主动刷新与详情返回。返回时保留已挂载列表、图片比例、已加载分页及滚动位置；必要的数据更新静默同步，失败保留旧内容，不退回第一页导致页面缩短。
- 保留请求版本校验，避免旧筛选响应覆盖新结果；验证详情中的收藏、目击等更新仍能反映到列表。
- 选课页弹层不再通过压缩整个页面高度锁滚动；采用局部遮罩阻止滚动穿透，弹层内容仍可滚动，不影响其他教务页。保留关闭、切换学期、资料跳转和订阅行为。
- 补充针对性回归测试，具体实现后更新文档。

## 涉及文件

- 猫猫列表页面及相关回归测试；必要时增加局部刷新状态辅助模块。
- 选课结果页面、局部弹层样式和回归测试；不全局删除其他页面依赖的 locked 样式。

## 验收

- 猫猫列表滚动至第二页，连续进入不同详情再返回，不出现全屏加载态，不丢分页、不跳滚动位置；横竖图高度稳定。
- 搜索、筛选、下拉刷新、加载更多与详情数据更新仍正确；失败和快速切换无旧响应覆盖。
- 选课列表滚动后打开、关闭详情（遮罩、关闭按钮、知道了），页面高度与滚动位置不变；弹层长内容可滚动，背景不穿透。
- 学期切换、资料入口、减少动态效果与暗色模式无回归。
- 运行 lint、typecheck、目标测试、设计令牌/字体/暗色测试、build:weapp 和 git diff --check。
- 模拟器或真机验证需明确记录；未复现的视觉路径不得声称通过。

## 实施与验证结果

- 猫猫列表：初始/筛选请求由 effect 驱动，详情返回时静默拉取已加载页，以 ID 更新现有卡片，不插入、删除、重排卡片，不重置分页。完整结果集变更由下拉刷新或筛选同步。旧请求版本校验保留，卸载时使请求失效；静默失败保留旧列表。移除卡片原有按压缩放。
- 选课页面：移除仅本页使用的动态高度锁；遮罩与 Sheet 通过 catchMove 阻止背景触摸滚动，局部移除背景模糊。详情与学期使用内部 ScrollView，学期按条目数估算紧凑高度并受视口上限约束，不修改共享教务样式。
- 新增 selection-sheet 回归脚本并接入 ci:check；猫猫回归覆盖保留卡片/顺序、空响应、分页与旧响应隔离的源码约束。
- 本地通过：lint、typecheck、test:cat-atlas、test:selection-sheet、test:mobile-interactions、test:design-tokens、test:typography、test:dark-mode、test:academic-verification-refresh、test:academic-exams、test:lottery、test:share、git diff --check。
- 本地开发构建 build:weapp 通过，接口显式配置为本地 8080；构建沿用已有样式顺序警告。
- 微信模拟器猫猫列表：第二页共 60 张无图卡片，从详情返回期间采样 58 次，卡片数始终 60，加载态数始终 0，scrollTop 始终为 1728。此证据不覆盖横竖照片和所有失败/筛选并发路径。
- 选课页本地账号没有课程记录。尝试的运行时测试数据未进入实际渲染路径，已恢复 wx mock 和原函数并刷新模拟器；未改写真实教务数据或持久化缓存。长列表弹层、背景防穿透与短/长学期列表的设备视觉验收尚未完成，不能视为通过。
