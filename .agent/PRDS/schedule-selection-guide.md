# Miniapp: 课表模拟选课引导动画

## Overview

在课程表和蹭课检索页面增加轻量、一次性的操作引导，让用户知道课表的空白节次格可以进入课程检索，以及蹭课页右下角悬浮“课表”按钮可以打开课表入口。引导不改变现有课表数据，也不写入服务端。

## User story

作为第一次使用课表功能的同学，我希望知道如何从课表指定时段寻找可蹭课或模拟选课课程，从而不需要额外阅读说明就能完成操作。

## Requirements

- 课表首次展示且页面可操作时显示引导动画；加载中、弹层打开或错误态不显示。
- 普通课程表提示“长按空白时段，可为该时段蹭课”，模拟选课课表提示“长按空白时段，可继续选课”。文案必须与当前真实交互一致。
- 引导动画指向课表区域，不遮挡课程格点击和长按，不改变已有的周视图、日视图、课程详情及课表清除行为。
- 引导在当前设备每天最多展示一次；用户下拉刷新、离开页面或动画结束后不重复打扰。
- 支持 `prefers-reduced-motion`，降低动态效果时保留静态提示文本。
- 普通课表和模拟课表共用样式，但按模式显示对应操作文案。
- 蹭课检索页的悬浮“课表”按钮显示一次点击引导，明确说明展开后可进入“模拟选课”和“我的课表”；引导动画不遮挡按钮本身。
- 课表引导使用按压手势、呼吸光圈和入场动效；蹭课页引导使用悬浮说明气泡、指向箭头和按钮脉冲，视觉上能明确提示可操作位置。

## Non-goals

- 本次不把长按入口改为普通点击，也不新增服务端接口。
- 不改变现有“长按节次格后打开蹭课/选课操作面板”的行为。

## Acceptance criteria

- 在开发者工具中打开普通课表，能看到一次引导动画，并能识别进入蹭课的操作方式。
- 在开发者工具中打开模拟选课课表，能看到对应的“选课”引导，动画不影响课表操作。
- 在开发者工具中打开蹭课检索页，能看到悬浮“课表”按钮的点击提示，并能正常展开“模拟选课”和“我的课表”。
- 当天再次进入课表不重复显示；次日可再次显示。
- `yarn lint`、`yarn typecheck`、课程冒烟测试、设计规范测试和 `yarn build:weapp` 通过。
