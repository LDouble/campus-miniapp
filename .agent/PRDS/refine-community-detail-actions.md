# Campus Miniapp：优化帖子详情互动操作区

**Priority:** High
**Status:** Done
**Type:** Enhancement
**Created:** 2026-08-21
**Last Updated:** 2026-08-21

## Overview

优化帖子详情页点赞、评论、分享区域，移除当前三个独立胶囊按钮及分享按钮的特殊尺寸，改为与帖子详情内容自然衔接的轻量操作栏。三个操作按等分槽位定位，但实际点击热区仅包围图标与数字或文字。同步消除帖子详情操作栏与评论标题对评论总数的重复表达，并移除评论标题中的数量胶囊；没有上方互动栏的跑腿、二手、找同行详情仍在评论标题内保留普通文本评论数。功能、计数、点赞动画、分享能力和无障碍语义保持不变。

## User Story

**As a** 浏览帖子详情的学生
**I want** 点赞、评论和分享入口清晰、整齐且不过度强调容器造型
**So that** 我能快速完成互动，同时将注意力留在帖子内容和评论上

## Current Problems

- 三个操作项分别使用浅色胶囊底板，视觉重量偏高，与详情页平整、克制的内容风格不一致。
- 点赞和评论使用带文字的胶囊，分享却是单独的小圆按钮，三者尺寸和信息层级不统一。
- `gap`、固定最小宽度和左右内边距共同占用空间，操作项没有形成稳定的三等分节奏。
- 点赞激活态同时改变底板和图标，状态表达过重。
- 操作栏已展示评论总数，评论区标题又通过“全部评论”和数量胶囊重复展示同一个数字。
- 评论标题的数字胶囊抢占章节标题层级，与评论内容之间形成了不必要的视觉组件。

## Design Direction

- 使用全宽三等分定位槽位；槽位自身不可点击，内部操作按钮按图标与数字或文字自适应宽度，不把整列变成热区。
- 操作区只保留顶部 `1rpx` 语义分隔线，与正文建立层级，不增加外层卡片或胶囊底板。
- 内部操作按钮保持至少 `88rpx` 高度，并围绕图标和文案保留克制的横向内边距，满足移动端约 `44px` 的触控热区要求。
- 点赞、评论显示实时数量；分享使用纯图标并保留可访问名称，降低右侧操作的视觉宽度。
- 默认态使用 Ousea 次级文字色；点赞后仅爱心图标、数字和文字使用点赞语义色，并保留现有轻量心跳动画。
- 按压态使用透明度反馈，不生成新的块状背景；暗色模式继续使用语义 Token。
- 在帖子详情中，上方互动栏已经提供评论入口和总数，因此评论列表不再重复渲染章节标题，互动栏下方直接进入评论内容。
- 在跑腿、二手、找同行等没有上方互动栏的详情中，评论区标题继续展示普通内联评论数，例如“评论 12”，但不使用胶囊。
- 分页存在时，底部入口可展示剩余评论数量，让数字只在能帮助用户判断是否继续加载时出现。

## Requirements

1. 移除 `.community-detail__action` 的胶囊圆角、浅色背景、固定最小宽度和横向内边距。
2. 点赞、评论、分享使用三个等宽的非交互定位槽位；实际操作按钮不得拉伸填满槽位。
3. 实际操作按钮触控高度不得低于 `88rpx`，图标建议为 `36rpx`，宽度仅由图标、文案及必要横向内边距组成。
4. 分享项使用纯图标，不显示“分享”文本，但必须保留与其他按钮一致的 `88rpx` 热区和 `ariaLabel`。
5. 点赞激活态不使用红色胶囊底板，仅通过激活爱心资产和点赞语义色表达。
6. 保留点赞接口调用、评论区滚动、微信分享、计数、动画、`ariaRole` 和 `ariaLabel`。
7. 保留 `Button::after` 清理，避免微信原生按钮边框影响布局。
8. 不新增页面局部颜色、间距或圆角常量；样式使用 Ousea / Global 与现有语义 Token。
9. 暗色模式下操作栏分隔线、默认文字和激活态均需保持足够对比度。
10. 帖子详情移除“全部评论 + 数量胶囊”整层章节标题，互动栏下方直接进入评论列表。
11. 跑腿、二手、找同行等无互动栏场景继续使用共享组件默认标题“评论 {总数}”，数量作为普通内联文本显示，不使用胶囊。
12. 帖子详情评论总数继续由操作栏实时展示；存在下一页时，“查看更多评论”可表达剩余数量，但不得重复显示总数胶囊。

## Implementation Overview

1. 调整帖子详情互动操作栏的盒子模型：三等分定位槽位包裹自适应宽度按钮，避免整栏可点击。
2. 收敛点赞、评论和分享项的尺寸与文本展示规则。
3. 将按压态改为透明度反馈，将点赞态收敛为前景色和图标变化。
4. 为共享评论组件增加默认开启的标题显示开关；帖子详情关闭标题，其他无互动栏场景继续保留普通文本总数，并按实际分页状态表达剩余评论。
5. 更新详情页视觉 smoke assertions，防止胶囊样式、过大热区、重复计数或隐藏分享文字回归。

## Acceptance Criteria

- 帖子详情的三个互动入口不再呈现为独立胶囊或圆形按钮。
- 三个入口按等宽槽位对齐，但点击热区只覆盖图标、数字或文字附近，不覆盖整列空白区域。
- 分享使用纯图标，操作栏整体高度紧凑，但实际按钮热区高度不小于 `88rpx`。
- 点赞前后不改变按钮底板；激活态只改变爱心与前景色。
- 帖子详情不再重复展示评论章节标题，互动栏下方自然衔接评论列表；常驻总数仅在互动栏出现。
- 无互动栏的跑腿、二手、找同行详情仍能在评论标题中看到普通文本总数。
- 点赞、评论、分享功能和无障碍描述均无回归。
- 浅色与暗色模式均符合 Ousea / Global token 约束。

## Risks and Constraints

- 视觉高度需与安全触控热区平衡，不能通过压缩到低于 `88rpx` 来追求紧凑；同时不能用整列拉伸扩大用户未预期的横向热区。
- 微信原生 `Button` 带有默认样式，分享项必须继续显式清理边框和外边距。
- 本次只调整帖子详情互动区，不扩散修改列表卡片或生活服务详情操作布局。
